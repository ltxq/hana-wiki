# AI และการตั้งค่า

ต้องการสร้างและจัดการตัวละครโรลเพลย์จำลองในเซิร์ฟเวอร์ ดูคู่มือ [`/npc`](npc-roleplay.md)

---

## `/guildbook`

เปิดหน้ารวมคู่มือแนะนำการคุยกับ Hana และการใช้งานฟังก์ชันต่าง ๆ ภายใน Discord

---

## `/statusai`

ดูสถานะปัจจุบันของ Hana ตามเวลาจริงของประเทศญี่ปุ่น เช่น กำลังทำกิจกรรมอะไร อยู่ในช่วงเวลาใดของวัน และสถานะบน Discord

รายละเอียดสถานะบางส่วนเป็นสิทธิ์ของ Hana Premium

---

## `/settingai`

แผงควบคุมส่วนตัวสำหรับผู้ใช้แต่ละคน (คนอื่นไม่สามารถมองเห็นได้):

- เปิด / ปิด การแท็กชื่อเมื่อ Hana ตอบกลับ
- เปิด / ปิด ความจำสำหรับเซิร์ฟเวอร์ปัจจุบัน
- เลือกแชร์ความจำที่คุณอนุญาตข้ามไปยังเซิร์ฟเวอร์อื่น
- ตั้งเขตเวลา (Timezone) ประจำตัวของคุณ
- เพิ่ม แก้ไข หรือลบข้อมูลโปรไฟล์ส่วนตัว (เช่น ชื่อเล่น วันสำคัญ หรือสิ่งของที่ชอบ)

> **ข้อควรระวัง:** ห้ามใส่ที่อยู่ เบอร์โทรศัพท์ รหัสผ่าน ข้อมูลการเงิน หรือข้อมูลส่วนบุคคลที่มีความละเอียดอ่อน ข้อมูลพื้นฐานเช่นชื่อเล่นหรือสิ่งที่ชอบก็เพียงพอแล้ว

Hana จะไม่สุ่มแท็กทักหาสมาชิกก่อน เพื่อป้องกันการรบกวน

---

## `/profile`

ดูข้อมูลโปรไฟล์ที่คุณระบุไว้และระดับคะแนนความสัมพันธ์กับ Hana ในเซิร์ฟเวอร์ปัจจุบัน

### ระดับความสัมพันธ์:

| คะแนน | ระดับ |
| :--- | :--- |
| 0–24 | คนรู้จัก |
| 25–100 | คุยบ่อย |
| 101–300 | เพื่อน |
| 301–500 | เพื่อนสนิท |

> Hana มีสถานะเป็นเพื่อนสนิทเท่านั้น และจะไม่เริ่มบทสนทนาเชิงชู้สาวหรือโรแมนติก

---

## `/hanainsights`

ตรวจสอบโควตา AI แพ็กเกจ และสิทธิ์การใช้งานของเซิร์ฟเวอร์ปัจจุบัน

---

## `/hanacontext` — สำหรับผู้ดูแลเซิร์ฟเวอร์

เปิดหน้าต่างจัดการบริบทเซิร์ฟเวอร์และ **โต๊ะเลขาประจำเซิร์ฟเวอร์ (Dedicated Server Secretary)** รองรับการเลือกห้องประจำใน 1 คลิกด้วย `ChannelSelectMenu`, การกรอกข้อมูลกฎเกณฑ์เซิร์ฟเวอร์, และการเชื่อมต่อ API Key ของผู้ดูแลโดยไม่กินโควตาบอทส่วนกลาง

อ่านรายละเอียดเพิ่มเติมได้ที่ [คู่มือเจ้าของเซิร์ฟเวอร์ & โต๊ะเลขา](../roomai-and-permissions.md)
