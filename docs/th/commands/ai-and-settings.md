# AI และการตั้งค่า

ต้องการสร้างและจัดการตัวละครโรลเพลย์จำลองในเซิร์ฟเวอร์ ดูคู่มือ [`/npc`](npc-roleplay.md)

---

## `/guildbook`

เปิดหน้ารวมคู่มือแนะนำการคุยกับ Hana และการใช้งานฟังก์ชันต่าง ๆ ภายใน Discord

---

## `/statusai`

ดูสถานะปัจจุบันของ Hana ตามเวลาญี่ปุ่น (JST) โดยเหลือเฉพาะข้อมูลที่จำเป็น:

- เวลาญี่ปุ่น
- ตอนนี้กำลังทำอะไร
- สถานที่
- อากาศซัปโปโร ฮอกไกโด
- การแต่งตัว
- อารมณ์วันนี้
- สุขภาพตอนนี้
- ความสนใจช่วงนี้
- Event วันนี้

นำ **บุคลิก / สรุป / พลังงานวันนี้ / สถานะ Discord / ปฏิทินมหาวิทยาลัย** ออกจากหน้านี้แล้ว

---

## `/settings`

แผงควบคุมส่วนตัวสำหรับผู้ใช้แต่ละคน (คนอื่นไม่สามารถมองเห็นได้) **เมนูภาษาอยู่บนหน้าแรกเลย** เปลี่ยนไทย / อังกฤษ / ญี่ปุ่น (หรืออัตโนมัติ) ได้ทันที:

- 🌐 เลือกภาษาได้จากหน้าแรก (แสดงเป็นภาษาที่คุณใช้อยู่ตอนนี้)
- เปิด / ปิด การแท็กชื่อเมื่อ Hana ตอบกลับ
- ตั้งเขตเวลา (Timezone) ประจำตัวของคุณ
- เพิ่ม แก้ไข หรือลบข้อมูลโปรไฟล์ส่วนตัว (เช่น ชื่อเล่น วันสำคัญ หรือสิ่งของที่ชอบ)
- ลบข้อมูลส่วนตัวได้จากหน้า **ข้อมูล**

> ความจำตอนนี้เป็นแบบสั้น จึงตัดปุ่ม **ดูความจำ** ออกแล้ว ข้อมูลความจำและความสัมพันธ์เก็บแยกตามเซิร์ฟเวอร์เสมอ และแชร์ข้ามเซิร์ฟเวอร์ไม่ได้

> **ข้อควรระวัง:** ห้ามใส่ที่อยู่ เบอร์โทรศัพท์ รหัสผ่าน ข้อมูลการเงิน หรือข้อมูลส่วนบุคคลที่มีความละเอียดอ่อน ข้อมูลพื้นฐานเช่นชื่อเล่นหรือสิ่งที่ชอบก็เพียงพอแล้ว

Hana จะไม่สุ่มแท็กทักหาสมาชิกก่อน เพื่อป้องกันการรบกวน

## `/profile`

ดูข้อมูลโปรไฟล์ที่คุณระบุไว้และระดับคะแนนความสัมพันธ์กับ Hana ในเซิร์ฟเวอร์ปัจจุบัน

### ระดับความสัมพันธ์:

| คะแนน | ระดับ |
| :--- | :--- |
| 0–24 | คนรู้จัก |
| 25–100 | คุยบ่อย |
| 101–300 | เพื่อน |
| 301–500 | เพื่อนสนิท |

> Hana มีสถานะเป็นเพื่อนสนิทเท่านั้น และจะไม่เริ่มบทสนทนาเชิงชู้สาวหรือโรแมนติก

---

## `/hanainsights`

ตรวจสอบโควตา AI รายสัปดาห์ของเซิร์ฟเวอร์ และฟีเจอร์ที่เปิดให้ทุกคน (Status แบบละเอียด, Hana Context, NPC Roleplay) ตอนนี้เปิดฟรีทุกอย่างในช่วงเบต้า ไม่มีแพ็กเกจ Premium

---

## `/hanacontext` — สำหรับผู้ดูแลเซิร์ฟเวอร์

เปิดหน้าต่างจัดการบริบทเซิร์ฟเวอร์และ **โต๊ะเลขาประจำเซิร์ฟเวอร์ (Dedicated Server Secretary)** รองรับการเลือกห้องประจำใน 1 คลิกด้วย `ChannelSelectMenu`, การกรอกข้อมูลกฎเกณฑ์เซิร์ฟเวอร์, และการเชื่อมต่อ API Key ของผู้ดูแลโดยไม่กินโควตาบอทส่วนกลาง

**Server Admin Hub** (คีย์กลาง ทางลัดไป NPC และโต๊ะเลขา) มีคำสั่งของตัวเองคือ [`/admin`](../roomai-and-permissions.md) แยกต่างหากจากหน้านี้

อ่านรายละเอียดเพิ่มเติมได้ที่ [คู่มือเจ้าของเซิร์ฟเวอร์ & โต๊ะเลขา](../roomai-and-permissions.md)
