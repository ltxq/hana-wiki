# ระบบตัวละคร NPC (Roleplay)

`/npc` คือระบบสร้างและจัดการตัวละครโรลเพลย์จำลองในเซิร์ฟเวอร์ โดยตัวละครจะพูดคุยและตอบกลับผ่าน Discord Webhook ทำให้มีชื่อและรูปโปรไฟล์เฉพาะตัวเหมือนมีสมาชิกตัวจริงอยู่ในห้อง

---

## จุดเด่นของระบบ

- **แสดงผลผ่าน Webhook**: ทุกคำตอบส่งในนามของ NPC มีชื่อและรูปภาพโปรไฟล์ตามที่กำหนด
- **สร้างง่ายใน 3 ช่อง (`/npc create`)**: กรอกเพียง ชื่อ, บุคลิก/นิสัย, และประโยคเปิดตัว ระบบจะสร้าง Webhook และทักทายเปิดตัวในห้องทันที
- **คุยได้เป็นธรรมชาติ**: สมาชิกสามารถคุยกับ NPC ได้ด้วยการ **Reply (ตอบกลับ)** ข้อความของตัวละคร หรือ **พิมพ์เอ่ยชื่อ NPC** ในห้อง
- **จำบทสนทนาได้จริง**: แต่ละตัวละครจำการสนทนากับคุณได้สูงสุด 12 รอบ (แยกต่อตัวละครและต่อผู้ใช้) ทำให้ตอบต่อเนื่องได้โดยไม่ต้องเริ่มใหม่ทุกครั้ง
- **เลือกโมเดลเอง**: เลือกได้ระหว่าง Gemini, OpenRouter (รวม DeepSeek, GPT, Claude) หรือระบุเอง
- **แยกโควตาอิสระ**: รองรับการใช้ API Key (Gemini หรือ OpenRouter) ส่วนตัวหรือคีย์ของเซิร์ฟเวอร์ ไม่ดึงโควตาบอทส่วนกลาง
- **ไม่ปนกับ Hana**: Hana ยังคงเป็นนักเรียนมัธยมปลายคุยเล่นในห้อง `/setroomai` ตามเดิม ส่วน NPC จะแสดงบทบาทตามที่คุณกำหนดอย่างอิสระ

## คำสั่งทั้งหมด (`/npc`)

| คำสั่งย่อย | คำอธิบาย | สิทธิ์ที่ต้องใช้ |
| :--- | :--- | :--- |
| `/npc create` | เปิดแบบฟอร์มสร้างตัวละคร NPC ใหม่ในห้องปัจจุบัน | สมาชิกทั่วไป / ตามการตั้งค่า |

## วิธีสร้างตัวละคร (`/npc create`)

1. พิมพ์คำสั่ง `/npc create` ในห้องแชตที่ต้องการให้ NPC ปรากฏตัว
2. กรอกแบบฟอร์ม Modal 3 ช่อง:
   - **ชื่อ NPC**: ชื่อที่จะแสดงใน Webhook (เช่น `Yami`, `คุณครูไอโกะ`, `Knight Arthur`)
   - **นิสัย / บุคลิก**: บทบาท พฤติกรรม น้ำเสียง และข้อจำกัดในการพูดคุย
   - **ประโยคเปิดตัว**: ข้อความทักทายแรกที่ NPC จะโพสต์ลงห้องทันทีที่สร้างเสร็จ
3. *(ทางเลือก)* อัปโหลดรูปภาพอวตาร หรือระบุลิงก์รูปภาพของ NPC
4. กดส่ง ระบบจะสร้าง Discord Webhook ประจำห้องและส่งประโยคเปิดตัวทันที!

---

## วิธีพูดคุยกับ NPC

สมาชิกในเซิร์ฟเวอร์สามารถโต้ตอบกับ NPC ได้ 2 วิธีง่าย ๆ:

### 1. ตอบกลับข้อความ (Reply)
กด **Reply** ข้อความใดก็ได้ที่ NPC เป็นผู้ส่ง แล้วพิมพ์ข้อความของคุณ ระบบจะดึงบริบทข้อความก่อนหน้าและให้ NPC ตอบกลับบทสนทนานั้นอย่างต่อเนื่อง

### 2. เอ่ยชื่อตัวละคร (Mention Name)
พิมพ์ข้อความในห้องโดยมี **ชื่อของ NPC** อยู่ในประโยค เช่น:
```text
สวัสดีจ้ะ Yami วันนี้การบ้านวิชาคณิตศาสตร์ยากจังเลย
```
NPC ที่มีชื่อตรงกันและประจำการอยู่ในห้องนั้นจะเข้ามาตอบข้อความของคุณ

## จัดการ NPC

### ดูรายชื่อ (`/npc list`)
พิมพ์ `/npc list` เพื่อดูตาราง NPC ทั้งหมดในเซิร์ฟเวอร์ ซึ่งจะแสดง:
- ID ของตัวละคร (สำหรับใช้อ้างอิงในคำสั่งอื่น)
- ชื่อตัวละคร
- ห้องที่ประจำการ
- ผู้สร้างตัวละคร

### ย้ายห้อง (`/npc move`)
```text
/npc move id:npc_xxxxxx channel:#roleplay-room
```
หากไม่ระบุตัวเลือก `channel` ตัวละครจะสามารถตอบได้ในทุกห้องที่รองรับ

### แก้ไขข้อมูล (`/npc edit`)
```text
/npc edit id:npc_xxxxxx
```
เปิดแบบฟอร์มสำหรับปรับปรุงชื่อ คำสั่งนิสัย หรือรูปภาพอวตารใหม่ แผงจัดการยังให้เลือก **โมเดล AI** และตั้งค่า **API Key** ของตัวละครนั้นโดยเฉพาะได้

### ลบตัวละคร (`/npc delete`)
```text
/npc delete id:npc_xxxxxx
```
ลบข้อมูลตัวละคร ประวัติการสนทนาที่เก็บไว้ และทำลาย Webhook ที่ผูกไว้ออกจากช่องอัตโนมัติ

---

## การตั้งค่า API Key

ตัวละครแต่ละตัวใช้คีย์ของตัวเองได้ เพื่อไม่ให้ไปกินโควตาของคีย์กลางของบอท:

1. พิมพ์ `/npc edit id:npc_xxxxxx`
2. กดปุ่ม **ตั้งค่า API Key**
3. วางคีย์ทีละบรรทัด (หนึ่งคีย์ต่อหนึ่งบรรทัด) แล้วบันทึก

ระบบจะหมุนเวียนคีย์ให้อัตโนมัติเมื่อคีย์ใดโดนจำกัดอัตรา (rate limit) และจะไม่ใช้คีย์ของคนอื่นหรือคีย์กลางของบอทแทน หากคีย์หมดหรือใช้ไม่ได้ ระบบจะแจ้งให้เจ้าของตัวละครทราบ

> ผู้ดูแลเซิร์ฟเวอร์สามารถตั้งคีย์กลางของทั้งเซิร์ฟเวอร์ได้ผ่านคำสั่ง `/admin` ซึ่ง NPC จะใช้เมื่อตัวละครไม่มีคีย์ของตัวเอง

## สิทธิ์ที่จำเป็นใน Discord

เพื่อให้ระบบ NPC ทำงานได้สมบูรณ์ บอทต้องได้รับสิทธิ์ต่อไปนี้ในห้อง:
- `Manage Webhooks` (จัดการเว็บฮุก - จำเป็นอย่างยิ่งเพื่อสร้างและส่งข้อความในนามตัวละคร)
- `View Channel` (ดูช่อง)
- `Send Messages` (ส่งข้อความ)
- `Read Message History` (อ่านประวัติข้อความ)
