# ระบบตัวละคร NPC (Roleplay)

`/npc` คือระบบสร้างและจัดการตัวละครโรลเพลย์จำลองในเซิร์ฟเวอร์ โดยตัวละครจะพูดคุยและตอบกลับผ่าน Discord Webhook ทำให้มีชื่อและรูปโปรไฟล์เฉพาะตัวเหมือนมีสมาชิกตัวจริงอยู่ในห้อง

> **อัปเดตใน v1.5.2:** `/npc` กลายเป็น **คำสั่งเดียวที่เปิดแผงปุ่ม** แล้ว (คำสั่งย่อย `create` / `list` / `move` / `edit` / `delete` ถูกย้ายเข้าปุ่มทั้งหมด) ใช้งานง่ายเหมือนโต๊ะเลขา (`/secretary`) ไม่ต้องจำชื่อคำสั่งย่อยหรือรหัสตัวละคร

---

## จุดเด่นของระบบ

- **คำสั่งเดียว ทำได้ทุกอย่างด้วยปุ่ม**: พิมพ์ `/npc` ครั้งเดียว แล้วกดปุ่ม/เลือกจากเมนูในแผงได้เลย
- **แสดงผลผ่าน Webhook**: ทุกคำตอบส่งในนามของ NPC มีชื่อและรูปภาพโปรไฟล์ตามที่กำหนด
- **สร้างง่ายใน 3 ช่อง**: กด **➕ สร้าง NPC ใหม่** แล้วกรอก ชื่อ, บุคลิก/นิสัย, และประโยคเปิดตัว ระบบจะสร้าง Webhook และทักทายเปิดตัวในห้องทันที
- **คุยได้เป็นธรรมชาติ**: สมาชิกสามารถคุยกับ NPC ได้ด้วยการ **Reply (ตอบกลับ)** ข้อความของตัวละคร หรือ **พิมพ์เอ่ยชื่อ NPC** ในห้อง
- **จำบทสนทนาได้จริง**: แต่ละตัวละครจำการสนทนากับคุณได้สูงสุด 12 รอบ (แยกต่อตัวละครและต่อผู้ใช้) และจะลืมเองเมื่อเงียบเกิน 6 ชั่วโมง
- **เลือกโมเดลเอง**: เมนูในหน้าจัดการตัวละครเปลี่ยน Gemini, OpenRouter (DeepSeek, GPT, Claude) หรือระบุเองได้ทันที
- **รองรับ 3 ภาษา**: ข้อความในแผงเปลี่ยนตามภาษาที่ตั้งไว้ใน `/settings` (ไทย / อังกฤษ / ญี่ปุ่น)
- **แยกโควตาอิสระ**: ตัวละครใช้ API Key ของตัวเองก่อน ถ้าไม่มีจะใช้คีย์กลางของเซิร์ฟเวอร์จาก `/admin` ไม่ดึงโควตาบอทส่วนกลาง
- **ไม่ปนกับ Hana**: Hana ยังคงเป็นนักเรียนมัธยมปลายคุยเล่นในห้อง `/setroomai` ตามเดิม ส่วน NPC จะแสดงบทบาทตามที่คุณกำหนดอย่างอิสระ

## เปิดแผงหลัก (`/npc`)

พิมพ์ `/npc` ในห้องแชตใดก็ได้ในเซิร์ฟเวอร์ Hana จะตอบแบบเฉพาะคุณ (Ephemeral) พร้อม:

- จำนวนตัวละครในเซิร์ฟเวอร์ และจำนวนที่เป็นของคุณ
- สถานะ API Key กลางของเซิร์ฟเวอร์
- รายการตัวละครตัวอย่าง (ชื่อ ห้องประจำ โมเดล แหล่งคีย์)
- **เมนูเลือกตัวละคร** เพื่อเข้าหน้าจัดการได้ทันที

ทุกคนเปิดแผงได้ ปุ่มสำหรับผู้ดูแล (**คลังคีย์กลาง**, **โต๊ะเลขา**) จะแสดงเฉพาะสมาชิกที่มีสิทธิ์จัดการช่องหรือจัดการเซิร์ฟเวอร์

### ปุ่มในแผงหลัก

| ปุ่ม | การทำงาน |
| :--- | :--- |
| ➕ **สร้าง NPC ใหม่** | เปิดแบบฟอร์ม 3 ช่องสำหรับสร้างตัวละครในห้องปัจจุบัน |
| 🎭 **ทั้งหมด** / 👤 **ของฉัน** | กรองรายการและเมนูให้แสดงทุกตัว / เฉพาะของคุณ |
| ❓ **วิธีใช้** | เปิดคู่มือสั้น ๆ ภายในแผง |
| 👑 **คลังคีย์กลาง** | ไปที่ `/admin` (เฉพาะแอดมิน) |
| 👩‍💼 **โต๊ะเลขา** | ไปที่ `/secretary` (เฉพาะแอดมิน) |
| 🔄 **รีเฟรช** | โหลดแผงใหม่หลังการเปลี่ยนแปลง |

## วิธีสร้างตัวละคร

1. พิมพ์ `/npc`
2. กด **➕ สร้าง NPC ใหม่**
3. กรอกแบบฟอร์ม:
   - **ชื่อ NPC** — ชื่อที่แสดงใน Webhook (เช่น `Yami`, `คุณครูไอโกะ`, `Knight Arthur`)
   - **นิสัย / บุคลิก** — บทบาท พฤติกรรม น้ำเสียง และข้อจำกัดในการพูดคุย
   - **ประโยคเปิดตัว** — ข้อความทักทายแรกที่ NPC จะโพสต์ลงห้องทันที
4. กดส่ง ระบบจะสร้าง Discord Webhook ประจำห้อง ส่งประโยคเปิดตัว และแสดงรหัสตัวละครในข้อความยืนยันแบบเฉพาะคุณ

---

## วิธีพูดคุยกับ NPC

### 1. ตอบกลับข้อความ (Reply)
กด **Reply** ข้อความใดก็ได้ที่ NPC เป็นผู้ส่ง แล้วพิมพ์ข้อความของคุณ ระบบจะใช้ประวัติการสนทนาของตัวละครนั้นตอบกลับอย่างต่อเนื่อง

### 2. เอ่ยชื่อตัวละคร (Mention Name)
พิมพ์ข้อความในห้องโดยมี **ชื่อของ NPC** อยู่ในประโยค เช่น:
```text
สวัสดีจ้ะ Yami วันนี้การบ้านวิชาคณิตศาสตร์ยากจังเลย
```
NPC ที่มีชื่อตรงกันและประจำการอยู่ในห้องนั้นจะเข้ามาตอบข้อความของคุณ

## จัดการตัวละคร

เลือกตัวละครจากเมนูในแผงหลัก เพื่อเปิดหน้าจัดการตัวละคร:

- **เมนูโมเดล** — เปลี่ยนผู้ให้บริการ/โมเดลได้ทันที เลือก **⚙️ กำหนดเอง** เพื่อพิมพ์ `provider:model` เอง
- 📝 **แก้ไขข้อมูล/รูป** — เปลี่ยนชื่อ นิสัย ประโยคเปิดตัว หรือลิงก์รูปโปรไฟล์
- 🔑 **ตั้งค่า API Key** — ตั้งหรือล้างคีย์ของตัวละคร
- 📍 **ย้ายห้อง** — เลือกห้องข้อความ หรือกด **🌐 อยู่ได้ทุกห้อง (Global)**
- 🗑️ **ลบตัวละคร** — มีการยืนยันก่อนลบจริง
- 📋 **กลับหน้าหลัก** — กลับไปยังแผงหลัก

### การตั้งค่า API Key

1. เปิดหน้าจัดการของตัวละคร
2. กดปุ่ม **🔑 ตั้งค่า API Key**
3. วางคีย์ทีละบรรทัดแล้วบันทึก หรือ **เว้นว่างแล้วบันทึกเพื่อล้างคีย์** ให้กลับไปใช้คีย์กลางของเซิร์ฟเวอร์จาก `/admin`

ระบบจะหมุนเวียนคีย์ให้อัตโนมัติเมื่อคีย์ใดโดนจำกัดอัตรา (rate limit) ตัวละครจะไม่ใช้คีย์ของสมาชิกคนอื่น และHana จะใช้คีย์กลางเป็นทางเลือกสุดท้ายตามที่แอดมินตั้งค่าไว้เท่านั้น

## สิทธิ์ที่จำเป็นใน Discord

เพื่อให้ระบบ NPC ทำงานได้สมบูรณ์ บอทต้องได้รับสิทธิ์ต่อไปนี้ในห้อง:
- `Manage Webhooks` (จัดการเว็บฮุก - จำเป็นอย่างยิ่งเพื่อสร้างและส่งข้อความในนามตัวละคร)
- `View Channel` (ดูช่อง)
- `Send Messages` (ส่งข้อความ)
- `Read Message History` (อ่านประวัติข้อความ)
