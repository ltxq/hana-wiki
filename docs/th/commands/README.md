# คำสั่งทั้งหมดของ Hana

รวมคำสั่ง Slash Commands ทั้งหมดของ Hana โดยแบ่งตามหมวดหมู่การใช้งาน:

---

## 💬 Hana AI และการตั้งค่าผู้ใช้

ใช้สำหรับเปิดห้องคุยเล่นกับ Hana ตรวจสอบตารางชีวิต และปรับแต่งการตั้งค่าส่วนบุคคล

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/setroomai` | เปิดใช้งานห้องสนทนา Hana AI สำหรับคุยเล่นกับสมาชิก |
| `/unsetroomai` | ปิดใช้งานห้องสนทนา Hana AI |
| `/guildbook` | เปิดคู่มือวิธีคุยและฟีเจอร์ต่าง ๆ บน Discord |
| `/statusai` | ดูสถานะและกิจกรรมประจำวันของ Hana ตามเวลาญี่ปุ่น |
| `/settingai` | ตั้งค่าส่วนตัว เช่น ความจำ เขตเวลา และข้อมูลโปรไฟล์ |
| `/profile` | ตรวจสอบข้อมูลโปรไฟล์และระดับความสัมพันธ์กับ Hana |

👉 อ่านเพิ่มเติมที่ [AI และการตั้งค่า](ai-and-settings.md)

---

## 🎭 ระบบตัวละคร NPC (Roleplay)

สร้างและบริหารตัวละครเสมือนจริงที่ตอบกลับด้วย Discord Webhook พร้อมรูปและชื่อประจำตัว

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/npc` | เปิดแผงปุ่มเดียวทำได้ทุกอย่าง: สร้าง ดูรายชื่อ/กรอง จัดการ (โมเดล ข้อมูล คีย์ ห้อง) และลบ ไม่ต้องจำคำสั่งย่อย |

👉 อ่านเพิ่มเติมที่ [ระบบตัวละคร NPC (Roleplay)](npc-roleplay.md)

---

## 🏢 การดูแลเซิร์ฟเวอร์และโต๊ะเลขา

ระบบสำหรับเจ้าของและผู้ดูแลเซิร์ฟเวอร์ในการจัดการข้อมูลและกฎระเบียบ

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/hanacontext` | แผงควบคุมและตั้งค่า **เลขาประจำเซิร์ฟเวอร์** พร้อมเมนูเลือกห้องใน 1 คลิก (มี `/secretary` เป็นชื่อเดิม) |
| `/admin` | ศูนย์รวมจัดการระบบ AI และตั้งค่า **API Key กลางของเซิร์ฟเวอร์** (เฉพาะผู้ดูแล) |
| `/hanainsights` | ดูโควตา AI การใช้งาน และแพ็กเกจของเซิร์ฟเวอร์ |

👉 อ่านเพิ่มเติมที่ [คู่มือเจ้าของเซิร์ฟเวอร์ & โต๊ะเลขา](../roomai-and-permissions.md)

## 🔊 ระบบอ่านออกเสียงในห้องเสียง (TTS)

ให้ Hana เข้าร่วมห้องเสียงเพื่ออ่านข้อความแชตแบบเรียลไทม์ พร้อมตัดแท็กและลิงก์อัตโนมัติ

| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/tts` | ให้ Hana เข้าร่วมห้องเสียงของคุณและเริ่มอ่านข้อความในแชต |
| `/leave` | ให้ Hana ออกจากห้องเสียงทันที |

👉 อ่านเพิ่มเติมที่ [ระบบอ่านออกเสียง TTS](tts.md)
