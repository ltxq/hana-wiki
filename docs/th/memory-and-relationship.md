# ความจำและความสัมพันธ์

## ความจำ

ความจำของ Hana เก็บแยกตาม **Discord User ID + Server ID** คุณจึงไม่ต้องกังวลว่าเรื่องที่คุยในเซิร์ฟเวอร์หนึ่งจะไปปนกับอีกเซิร์ฟเวอร์หนึ่ง ความสัมพันธ์ของคุณก็เก็บแยกกันในแบบเดียวกัน

คุณควบคุมได้จาก `/settings`:

- เลือกภาษาที่ Hana ใช้แสดงผลได้จาก **หน้าแรกเลย**
- แก้ไขข้อมูลโปรไฟล์ส่วนตัวและเขตเวลา
- เปิดหรือปิดการแท็กชื่อเมื่อ Hana ตอบกลับ และการแสดง reaction
- ลบข้อมูลส่วนตัวของคุณ (มีขั้นตอนยืนยัน) จากหน้า **ข้อมูล**

ความจำตอนนี้เป็นแบบสั้น จึงตัดปุ่ม **ดูความจำ** ออกแล้ว ความจำและความสัมพันธ์เก็บแยกตามเซิร์ฟเวอร์เสมอ และแชร์ข้ามเซิร์ฟเวอร์ไม่ได้

Hana ไม่ควรเดาข้อมูลที่คุณไม่ได้กรอกเอง เช่น อายุ ชื่อจริง หรือประเทศ

> ถ้าคุณไม่ต้องการให้ Hana เก็บอะไรเกี่ยวกับคุณเลย ให้ใช้ `/settings` → **ข้อมูล** → **ลบทั้งหมด** ซึ่งจะลบทั้งความจำของเซิร์ฟเวอร์นี้และคะแนนความสัมพันธ์ของคุณด้วย

## ความสัมพันธ์

คะแนนความสัมพันธ์แยกตามผู้ใช้และเซิร์ฟเวอร์ จึงไม่กระทบคะแนนของคุณในเซิร์ฟเวอร์อื่น

คะแนนเพิ่มช้า ๆ จากการคุยอย่างสุภาพ ต่อบทสนทนา สนใจสิ่งที่ Hana ชอบ หรือจำรายละเอียดเล็ก ๆ ได้ ไม่เพิ่มจากการสแปม

คะแนนอาจลดจากการกดดัน ล้ำเส้น หยาบคาย หรือขอคบ/จีบอย่างจริงจัง Hana จะปฏิเสธอย่างสุภาพและรักษาขอบเขตความเป็นเพื่อน

หลังจาก Hana ขอเว้นระยะ ต้องมีทั้ง **อย่างน้อย 3 บทสนทนาปกติ** และ **อย่างน้อย 3 วัน** ถึงจะกลับมาเป็นเพื่อนปกติได้

Hana จะไม่ใช้ความจำเพื่อสุ่มแท็กทักก่อน ระบบดังกล่าวถูกถอดออกเพื่อไม่รบกวนสมาชิก

## ภาษาที่รองรับ

Hana คุยกลับเป็นภาษาเดียวกับที่คุณเขียน โดยรองรับ **ไทย อังกฤษ และญี่ปุ่น** ถ้าคุณเขียนด้วยภาษาที่ไม่รองรับ Hana จะบอกว่าอ่านได้แค่สามภาษานี้ และจะไม่ส่งข้อความนั้นไปหาผู้ให้บริการ AI

ภาษาของหน้าต่างตั้งค่าและข้อความจากบอท ตั้งได้ที่ **หน้าแรกของ `/settings`** เลย เลือกได้ ไทย / อังกฤษ / ญี่ปุ่น หรือ "อัตโนมัติ" เพื่อให้ Hana ตามภาษาที่คุณคุย
