# เริ่มใช้งาน Hana

คู่มือเริ่มต้นสำหรับผู้ดูแลและสมาชิกใหม่ในการนำ Hana มาสร้างบรรยากาศที่มีชีวิตชีวาในเซิร์ฟเวอร์

---

## 1. เพิ่ม Hana เข้าเซิร์ฟเวอร์

เจ้าของหรือผู้ดูแลเซิร์ฟเวอร์เชิญ Hana เข้า Discord แล้วเปิดสิทธิ์พื้นฐานในห้องที่ต้องการใช้งาน:
- `View Channel` & `Send Messages`
- `Read Message History` & `Embed Links`
- `Manage Webhooks` (จำเป็นหากต้องการใช้ระบบตัวละคร `/npc`)
- `Connect` & `Speak` (จำเป็นหากต้องการใช้ระบบอ่านเสียง `/tts`)

---

## 2. ตั้งห้องคุยเล่นกับ Hana (`/setroomai`)

ผู้ดูแลพิมพ์ `/setroomai` ในห้องที่ต้องการให้ Hana เข้ามาคุยเล่น จากนั้นสมาชิกทุกคนสามารถพิมพ์คุยเล่นกับ Hana ได้ทันทีอย่างเป็นธรรมชาติ

Hana รองรับภาษาไทย อังกฤษ และญี่ปุ่นอย่างคล่องแคล่ว

---

## 3. ตั้งโต๊ะเลขาประจำเซิร์ฟเวอร์ (`/hanacontext`)

สำหรับเซิร์ฟเวอร์ที่ต้องการบอทช่วยตอบคำถามเรื่องกฎระเบียบ นำทางช่อง และอธิบายยศ:
1. ผู้ดูแลพิมพ์ `/hanacontext`
2. เลือกห้องประจำของเลขาจากเมนูดรอปดาวน์
3. กรอกข้อมูลและกฎเซิร์ฟเวอร์พร้อมใส่ API Key (Gemini หรือ OpenRouter)
4. เลขาจะประจำการและตอบคำถามเรื่องเซิร์ฟเวอร์ให้สมาชิกโดยเฉพาะ

---

## 4. สร้างตัวละครโรลเพลย์ (`/npc create`)

สร้างตัวละครเสมือนจริงที่ตอบกลับด้วย Webhook ในห้องแชต:
1. พิมพ์ `/npc create`
2. กรอกชื่อ นิสัย และประโยคเปิดตัว
3. สมาชิกสามารถคุยกับ NPC ได้ด้วยการ Reply หรือพิมพ์เอ่ยชื่อตัวละคร

---

## 5. ใช้งานระบบอ่านออกเสียง (`/tts`)

เข้าห้องเสียงแล้วพิมพ์คำสั่ง `/tts` ในห้องแชต Hana จะเข้าห้องเสียงและเริ่มอ่านข้อความของสมาชิกทันที และออกจากห้องเสียงเมื่อพิมพ์ `/leave`

---

## 6. ตั้งค่าส่วนตัว (`/settingai`)

สมาชิกแต่ละคนสามารถใช้ `/settingai` เพื่อตั้งค่าเขตเวลา จัดการความจำ หรือระบุชื่อเล่นให้ Hana เรียกอย่างสนิทสนม
