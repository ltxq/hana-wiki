# คู่มือเจ้าของเซิร์ฟเวอร์ & โต๊ะเลขา

หน้านี้รวบรวมวิธีตั้งค่าห้องสนทนา Hana AI, การตั้งค่าโต๊ะเลขาประจำเซิร์ฟเวอร์ด้วย `/hanacontext`, และการกำหนดสิทธิ์ Discord ที่จำเป็น

---

## 1. ห้องสนทนา Hana AI (`/setroomai`)

คำสั่งสำหรับผู้ดูแลเซิร์ฟเวอร์ในการเปิดหรือปิดให้ Hana เข้ามาคุยเล่นกับสมาชิก:

| คำสั่ง | คำอธิบาย | สิทธิ์ที่ต้องใช้ |
| :--- | :--- | :--- |
| `/setroomai` | เปิด Hana AI ในห้องปัจจุบัน ให้สมาชิกคุยเล่นได้ | `Manage Channels` |
| `/unsetroomai` | ปิดการทำงานของ Hana AI ในห้องปัจจุบัน | `Manage Channels` |
| `/guildbook` | แสดงคู่มือการคุยและเล่นกับ Hana บน Discord | สมาชิกทุกคน |

> **หมายเหตุ:** Hana ในห้อง AI คือเด็กสาวมัธยมปลาย ร่าเริง ชอบ Splatoon ขนมหวาน และคุยเรื่องทั่วไป โดยไม่แบกรับหน้าที่แอดมินหรือกฎของเซิร์ฟเวอร์

---

## 2. ระบบโต๊ะเลขาประจำเซิร์ฟเวอร์ (`/hanacontext`)

คำสั่ง `/hanacontext` ใช้สำหรับตั้งค่า **เลขาประจำเซิร์ฟเวอร์ (Dedicated Server Secretary)** เพื่อทำหน้าที่ตอบคำถาม ให้คำแนะนำเกี่ยวกับเซิร์ฟเวอร์ นำทางช่อง และอธิบายกฎระเบียบแก่สมาชิก

### ขั้นตอนการตั้งค่าโต๊ะเลขา

1. พิมพ์คำสั่ง `/hanacontext` (ต้องมีสิทธิ์ `Manage Guild` หรือผู้ดูแล) แล้วกด **ตั้งค่าเลขา / อัปเดตโต๊ะเลขา**
2. **เลือกห้องประจำของเลขา**: กดเลือกห้องจากกล่องเมนู `ChannelSelectMenu` ได้ทันที ไม่ต้องพิมพ์ชื่อหรือรหัสห้อง
3. **เลือกโมเดล AI จากเมนู**: กดเลือกจากรายการที่เตรียมไว้ให้เลย (แนะนำ Gemini 3.1 Flash Lite, หรือ Gemini 2.5 Flash/Pro, หรือโมเดล OpenRouter) ไม่ต้องพิมพ์ provider/model เอง
4. แบบฟอร์มสุดท้ายมีแค่ **ชื่อเลขา** (เช่น `เลขาซากิ`), **ลิงก์รูปโปรไฟล์** (ไม่บังคับ) และ **ประโยคเปิดโต๊ะต้อนรับ**
5. กดบันทึก เลขาจะพร้อมประจำการในห้องที่เลือกทันที!

> ตัดช่องใส่ API Key ออกจากการตั้งเลขาแล้ว ให้ตั้ง **คีย์กลางของเซิร์ฟเวอร์** ที่คำสั่ง `/admin` เพียงครั้งเดียว เลขาจะใช้คีย์นั้นอัตโนมัติ ส่วนข้อมูลกฎ/บริบทเซิร์ฟเวอร์ตั้งจากปุ่มแยกใน `/hanacontext`

### Strict Server-Only Boundary Guardrail (การจำกัดขอบเขตเข้มงวด)

เลขาประจำเซิร์ฟเวอร์ได้รับการออกแบบระบบป้องกัน (Guardrails) ไว้อย่างเคร่งครัด:
- **ตอบเฉพาะเรื่องเซิร์ฟเวอร์**: เลขาจะตอบคำถามเกี่ยวกับกฎระเบียบ ประกาศ กิจกรรม และข้อมูลของเซิร์ฟเวอร์เท่านั้น
- **ปฏิเสธคำถามนอกเรื่องอย่างสุภาพ**: หากสมาชิกชวนคุยเล่น ถามเรื่องสภาพอากาศ ขอให้เล่าเรื่องตลก หรือโรลเพลย์ทั่วไป เลขาจะปฏิเสธอย่างสุภาพ และแนะนำให้ถามเรื่องที่เกี่ยวกับเซิร์ฟเวอร์ หรือชวนคุยเล่นกับ Hana ในห้อง `/setroomai` แทน
- **ตอบเป็นภาษาผู้พูดเสมอ**: เลขาตอบเป็นภาษาไทย อังกฤษ หรือญี่ปุ่น ตามที่สมาชิกเขียนถาม รวมถึงคำปฏิเสธเรื่องนอกขอบเขตด้วย

### การจำบทสนทนา

เลขาจำการสนทนากับคุณได้สูงสุด 12 รอบ (แยกต่อเซิร์ฟเวอร์และต่อสมาชิก) ทำให้ถามต่อเนื่องได้โดยไม่ต้องทวนเรื่องใหม่ เช่นถามว่า "แล้วช่องไหนคะ" ต่อจากคำถามก่อนหน้า ประวัตินี้จะถูกลบอัตโนมัติเมื่อไม่มีการใช้งานเกิน 6 ชั่วโมง

### การล้างหรือรีเซ็ตข้อมูล
ภายในหน้าต่าง `/hanacontext` ผู้ดูแลสามารถกดปุ่มเพื่อ:
- ลบข้อมูลบริบทหรือกฎเซิร์ฟเวอร์
- ล้างการตั้งค่าเลขา
- ตรวจสอบสถานะคีย์กลางของเซิร์ฟเวอร์ได้ที่ `/admin`

## 3. สิทธิ์ที่แนะนำใน Discord

Hana ไม่จำเป็นต้องใช้สิทธิ์ Administrator เต็มรูปแบบ สามารถเปิดเฉพาะสิทธิ์ที่จำเป็นตามตารางนี้:

| สิทธิ์ | วัตถุประสงค์การใช้งาน |
| :--- | :--- |
| `View Channel` | มองเห็นห้องข้อความและห้องเสียง |
| `Send Messages` | ตอบกลับข้อความในห้องแชต |
| `Read Message History` | อ่านบริบทข้อความก่อนหน้าเพื่อตอบให้ตรงประเด็น |
| `Embed Links` | แสดงการ์ดข้อมูล Embed (จำเป็นสำหรับ `/travelphoto`, โปรไฟล์ และคู่มือ) |
| `Attach Files` | แนบรูปภาพท่องเที่ยวญี่ปุ่น |
| `Use Application Commands` | ให้สมาชิกพิมพ์คำสั่ง Slash Commands ได้ |
| `Manage Webhooks` | **จำเป็นสำหรับระบบ NPC** (`/npc`) ในการสร้างและส่งข้อความตัวละคร |
| `Connect` & `Speak` | **จำเป็นสำหรับระบบ TTS** (`/tts`) ในการเข้าห้องเสียงและอ่านข้อความ |
| `Send Messages in Threads` | ตอบข้อความหากห้องนั้นมีการเปิดใช้งานเธรด |

## 4. การแก้ปัญหาเมื่อบอทไม่ตอบ

1. **Hana ไม่ตอบในห้องแชต**:
   - ตรวจสอบว่าเปิดห้องด้วย `/setroomai` แล้วหรือไม่
   - ตรวจดูว่า Hana มีสิทธิ์ `View Channel`, `Send Messages`, และ `Read Message History` หรือไม่
   - ตรวจสอบ Channel Permission Overrides ว่ามีบทบาทใดตั้งค่าปฏิเสธ (Deny) สิทธิ์ไว้หรือไม่
2. **เลขาประจำเซิร์ฟเวอร์ไม่ตอบ**:
   - ตรวจสอบว่าแอดมินเลือกห้องประจำการผ่าน `/hanacontext` ถูกต้องหรือไม่
   - ตรวจสอบว่า API Key (Gemini / OpenRouter) ยังมีโควตาใช้งานได้ปกติ
3. **NPC ไม่ตอบข้อความ**:
   - ตรวจสอบว่าบอทได้รับสิทธิ์ `Manage Webhooks` ในห้องนั้นหรือไม่
   - ดูว่าสมาชิกได้ทำการ Reply ที่ข้อความของ NPC หรือพิมพ์เอ่ยชื่อ NPC ถูกต้องหรือไม่
4. **รูปภาพไม่แสดงใน `/travelphoto`**:
   - ตรวจสอบว่าห้องนั้นเปิดสิทธิ์ `Embed Links` ให้ Hana แล้วหรือไม่
