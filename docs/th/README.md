# หน้าแรก

Hana คือ Discord App ที่คุยเป็นธรรมชาติ มีตารางชีวิตประจำวันแบบญี่ปุ่น ช่วยสร้างบรรยากาศที่มีชีวิตชีวาให้กับคอมมูนิตี้ พร้อมระบบตัวละครจำลอง (NPC), โต๊ะเลขาประจำเซิร์ฟเวอร์, ระบบอ่านเสียง TTS, และคำสั่งสนุก ๆ ให้ใช้งานร่วมกัน

> 🌸 Hana รองรับภาษาไทย อังกฤษ และญี่ปุ่นอย่างเป็นธรรมชาติ

## ฟีเจอร์เด่นของ Hana

| หมวด | รายละเอียดและความสามารถ |
| :--- | :--- |
| **Hana AI Chat** | คุยเล่นอย่างเป็นธรรมชาติ มีความจำ ตารางชีวิตประจำวัน และความสนใจเรื่องเกม Splatoon |
| **NPC Roleplay** | สร้างตัวละครจำลองตอบกลับผ่าน Discord Webhook พร้อมรูปและชื่อประจำตัว โต้ตอบได้ด้วยการ Reply |
| **Server Secretary** | โต๊ะเลขาประจำเซิร์ฟเวอร์ ตอบเฉพาะกฎ ระเบียบ และนำทางช่องทางต่าง ๆ อย่างแม่นยำ |
| **Voice & TTS** | อ่านออกเสียงข้อความแชตในห้องเสียง ตัดแท็กและลิงก์อัตโนมัติ พร้อมระบบกันสแปม |
| **Fun & Travel** | ค้นหาภาพท่องเที่ยวญี่ปุ่นจาก Pexels, อนิเมะ GIF ท่าทาง, และมินิเกม |
