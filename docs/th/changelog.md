# Changelog

## HanaBot v1.5.2 — 25 พฤศจิกายน 2026

- **⚙️ ปรับคำสั่งใหม่ (ช่วงเบต้า)**:
   - เปลี่ยน `/settingai` เป็น **`/settings`** ย้ายตัวเลือกภาษาขึ้นมาที่ **หน้าแรก** และตัดปุ่ม **ดูความจำ** ออกเพราะความจำเป็นแบบสั้นแล้ว
   - นำ `/premium` ออก เปิดฟรีทุกฟีเจอร์ในช่วงเบต้า และลบข้อความ/ปุ่มล็อก Premium ออกจาก `/statusai`, `/hanainsights` และโต๊ะเลขา
   - ลบคำว่า "(ฟรี)" ออกจากรายละเอียดใต้คำสั่ง
   - `/statusai` เหลือเฉพาะสิ่งจำเป็น: เวลาญี่ปุ่น ตอนนี้ สถานที่ อากาศ การแต่งตัว อารมณ์ สุขภาพ ความสนใจ และ Event วันนี้ (ตัด บุคลิก / สรุป / พลังงาน / สถานะ Discord / ปฏิทินมหาวิทยาลัย ออก)
   - แก้บั๊กที่หน้าต่างบางแห่งโชว์ key ดิบ เช่น `common.status:` หรือ `settings.memory.title:` แทนข้อความภาษาปกติ
   - การตั้งเลขาเปลี่ยนเป็น **เมนูเลือกโมเดล** (ไม่ต้องพิมพ์ provider/model เอง) และตัดช่องใส่ API Key ออก ให้ตั้งคีย์กลางที่ `/admin` แทน
   - Gemini error 503 แสดงเป็นข้อความไทยสั้น ๆ แบบ Hana เวลาตอบไม่ได้ แทนการโชว์ JSON ดิบ (เลขา / NPC / RoomAI)
   - **ตั้งโมเดล AI กลางที่ `/admin`** ได้จากปุ่มหรือพิมพ์ `/admin model:`autocomplete แยกปุ่มชัดเจนเป็น **Gemini** กับ **OpenRouter** (Gemini เหลือเฉพาะรุ่น 3.1 Flash ขึ้นไป รุ่น 2.x เก่าถอดออกแล้ว) โมเดล OpenRouter ฟรีอยู่หน้าสุดเสมอ แบ่งหน้าและค้นหาได้ เลขา/NPC ใช้ค่านี้เป็นค่าเริ่มต้น แต่เปลี่ยนรายตัวได้
   - จัดหน้า **Server Admin Hub** ใหม่ให้เป็นหมวดหมู่อ่านง่าย มีการเว้นวรรค และแบ่งปุ่มเป็น 3 แถวสั้น ๆ
   - **optimize token ใน prompt**: แยกบทบาทพ่อ-ลูกออกเป็น prompt อีกแบบที่เลือกตาม Discord User ID — เฉพาะเจ้าของเท่านั้นที่จ่าย token ตรงนี้ สมาชิกทั่วไปได้ prompt แบบเพื่อนธรรมดา ไม่มีบริบท Sky/พ่อ และไม่ถูก Hana เรียกว่าพ่ออีก
   - **ความแม่นยำของอากาศ**: แนบอากาศจริงซัปโปโรแบบสั้นทุก request (รายละเอียดเฉพาะตอนถาม) และ event "หิมะแรก" จะเกิดก็ต่อเมื่อ API อากาศรายงานว่ามีหิมะจริง ไม่ใช่แค่ตามวันที่ในตาราง
   - แยกตัวประกอบ prompt ไปที่ `System/roomai-prompt.js` และเทสจริง (prompt ของ owner กับคนทั่วไป, อากาศถูกแนบ, event ผูกอากาศ) แทนการเทสแค่ข้อความในโค้ด
   - **เพิ่มภาษาที่ 3 ให้แผงอื่น ๆ**: `/statusai`, `/guildbook`, `/hanainsights`, Admin Hub, แผงเลือกโมเดล และขั้นตอนตั้งเลขา ตอนนี้เปลี่ยนตามภาษาที่เลือกใน `/settings` แล้ว
   - **ขยายตัวเลือกโมเดล OpenRouter เป็นหลายร้อยตัว** ดึงจากรายชื่อจริงของ OpenRouter (กรองตัวที่ใช้แชทไม่ได้/หมดอายุออกแล้ว) ค้นหาและแบ่งหน้าได้ และ **ตัดคำว่า "ฟรี" ออก** เพราะผู้ให้บริการเปิดให้ลองชั่วคราว ไม่มีรายชื่อถาวร
   - **ยกเลิกเกณฑ์จำนวนสมาชิก**: เพิ่มบอทเข้าเซิร์ฟเวอร์เล็ก ๆ จะไม่ถูกแจ้งเตือนว่าไม่ผ่านเกณฑ์ และบอทจะไม่ออกจากเซิร์ฟเวอร์เอง — เก็บข้อมูลเซิร์ฟเวอร์ (ชื่อ เจ้าของ จำนวนสมาชิก) ลง log แทน
   - **คุยต่อตอนนอนได้แบบไม่รบกวนคนอื่น**: ถ้าคุณพิมพ์ 2 ข้อความติดกันตอน Hana นอน จะมีข้อความเห็นแค่คุณถามว่าอยากให้ตอบต่อไหม พร้อมปุ่ม ✅ เอา / ❌ ไม่เป็นไร
   - **ปุ่มใน `/settings` เปลี่ยนความหมาย**: จาก "ไม่รอตารางทั้งหมด" เป็น **ข้ามเฉพาะช่วงนอน** — กิจกรรม/ตารางอื่นยังเหมือนเดิม และปุ่มในข้อความเสนอกับปุ่มใน `/settings` จะตรงกันเสมอ
   - ลบคำทัก "หายไปไหนมาเนี่ย" ออกจากตอนกลับมาคุยแล้ว
- **🎭 `/npc` กลายเป็นแผงปุ่มคำสั่งเดียว**:
   - รวมคำสั่งย่อยทั้ง 5 (`create` / `list` / `move` / `edit` / `delete`) เป็น `/npc` คำสั่งเดียวที่เปิดแผงหลักกดปุ่มได้ง่าย ๆ เหมือนโต๊ะเลขา
   - สร้าง กรอง (ทั้งหมด/ของฉัน) เลือกตัวละครจากเมนู เปลี่ยนโมเดล แก้ไขข้อมูล/คีย์/ห้อง และลบ ได้โดยไม่ต้องพิมพ์รหัสหรือชื่อคำสั่ง
   - แผงทั้งหมดแปลเป็นไทย/อังกฤษ/ญี่ปุ่น และการล้างคีย์ตัวละครตอนนี้กลับไปใช้คีย์กลางของเซิร์ฟเวอร์ได้จริง
- **🔒 ความจำแยกตามเซิร์ฟเวอร์แล้ว**:
  - ความจำและความสัมพันธ์เก็บแยกตาม **Discord User ID + Server ID** เรื่องที่คุยในเซิร์ฟเวอร์หนึ่งไม่ปนไปอีกเซิร์ฟเวอร์หนึ่ง
  - ความจำเดิมแบบรวมทั้งเซิร์ฟเวอร์ยังเก็บสำรองไว้ใน state แต่ปุ่มย้ายหายไปพร้อมกับหน้าความจำ
  - งานสรุปความจำแยกตามผู้ใช้+เซิร์ฟเวอร์ ไม่เขียนทับข้ามเซิร์ฟเวอร์
- **🌐 หน้าต่างตั้งค่ารองรับ 3 ภาษา**:
  - ตัวเลือกภาษาอยู่ที่ **หน้าแรกของ `/settings`** (ไทย / อังกฤษ / ญี่ปุ่น หรืออัตโนมัติตามภาษาที่คุณคุย)
  - หน้าตั้งค่า หน้าความจำ หน้าข้อมูลส่วนตัว และหน้าโปรไฟล์ แปลตามภาษาที่เลือก
- **🔑 คีย์ API แบบเฉพาะตัว**:
  - โต๊ะเลขาตั้งคีย์เฉพาะของตัวเองได้ผ่านช่อง `sec_keys` ในแบบฟอร์ม (ถ้าเว้นว่างจะใช้คีย์กลางของเซิร์ฟเวอร์)
  - NPC ตั้งคีย์เฉพาะของตัวละครได้จากปุ่ม **ตั้งค่า API Key** ในแผงจัดการ NPC
  - แผงจัดการ NPC แยกเป็น 2 แถวปุ่ม เพื่อให้มีทั้งคีย์เฉพาะตัวละครและคีย์กลาง
- **เอกสารและนโยบายอัปเดต**: อธิบายการแยกความจำตามเซิร์ฟเวอร์ให้ตรงกับโค้ดจริง

## HanaBot v1.5.1 — 25 พฤศจิกายน 2026

- **ระบบแปลภาษา 3 ภาษา (ไทย / อังกฤษ / ญี่ปุ่น)**:
  - ย้ายข้อความหน้าเว็บและหน้าต่างตั้งค่าไปไว้ใน `locales/` เพื่อให้แปลทีละภาษาได้
  - ข้อความโควตา AI และคิวเต็มตอบเป็นภาษาผู้ใช้จริงแล้ว ไม่ใช่ภาษาไทยล้วน
  - เลขาประจำเซิร์ฟเวอร์ปฏิเสธคำถามนอกเรื่อง **เป็นภาษาของผู้พูด** แทนที่จะตอบเป็นภาษาไทยเสมอ
  - รองรับภาษาญี่ปุ่นในระบบค้นความจำและคำถามเกี่ยวกับ Splatoon
  - `/travelphoto` ค้นหาจังหวัดได้จากชื่อภาษาไทย อังกฤษ และญี่ปุ่น
- **NPC และเลขาจำบทสนทนาได้แล้ว**:
  - NPC จำการสนทนากับคุณได้สูงสุด 12 รอบ (แยกต่อตัวละครและต่อผู้ใช้) แทนที่จะลืมทุกประโยค
  - เลขาประจำเซิร์ฟเวอร์จำการสนทนาได้เช่นกัน จึงถามต่อเนื่องได้โดยไม่ต้องทวน
- **แก้บั๊ก**:
  - โจทย์วาดรูปใน `/hanagame` เรียก AI จริงแล้ว และ **นับโควตาถูกต้อง** (ก่อนหน้านี้โค้ดส่วนนี้ตายและไม่เคยทำงาน)
  - ลบไฟล์ขยะที่ไม่มีโค้ดใช้แล้ว (แคช GIF, ฐานข้อมูล Private AI, โมดูลสำรอง)
- **เอกสารและนโยบายอัปเดต**:
  - Privacy Policy และ Terms of Service เขียนใหม�ให้ตรงกับฟีเจอร์ที่มีจริง (ตัดส่วน Private AI และ `/dmpanel` ที่ถูกลบไปแล้ว)
  - ระบุให้ชัดว่า **ความจำเก็บรวมทั้งเซิร์ฟเวอร์ (ต่อ User ID)** ส่วน **ความสัมพันธ์เก็บแยกตามเซิร์ฟเวอร์** ตามโค้ดจริง
  - เพิ่มคำอธิบาย NPC, เลขาประจำเซิร์ฟเวอร์ และคำสั่ง `/admin` ในคู่มือ

## HanaBot v1.5.0 — พฤศจิกายน 2026

- **ระบบตัวละคร NPC สำหรับ Roleplay (`/npc`)**:
  - ยกเลิกระบบ Private AI เดิม และเปิดตัวระบบ Custom Webhook NPC เต็มรูปแบบ
  - สร้างตัวละครได้สะดวกรวดเร็วผ่าน Modal 3 ช่อง (`/npc create`): ชื่อ, บุคลิก/นิสัย, และประโยคเปิดตัว
  - ตอบกลับข้อความผ่าน Discord Webhook ด้วยชื่อและรูปโปรไฟล์เฉพาะตัวของ NPC
  - โต้ตอบได้ลื่นไหลผ่านการ **Reply** ข้อความของ NPC หรือ **เอ่ยชื่อตัวละคร** ในห้อง
  - จัดการวงจรตัวละครครบวงจร: `/npc list`, `/npc move`, `/npc edit`, `/npc delete`
  - รองรับการเชื่อมต่อคีย์ API (Gemini/OpenRouter) แบบไม่ดึงโควตาบอทส่วนกลาง
- **ระบบโต๊ะเลขาประจำเซิร์ฟเวอร์ (`/hanacontext`)**:
  - แยกข้อมูลการดูแลเซิร์ฟเวอร์ออกจากตัวตนคุยเล่นของ Hana อย่างสิ้นเชิง
  - เพิ่มการเลือกห้องประจำของเลขาใน 1 คลิก ด้วย Discord `ChannelSelectMenu`
  - ตั้งค่าเลขาผ่าน Modal พร้อมกรอกบริบทกฎเกณฑ์และคีย์ API ของผู้ดูแล
  - เพิ่ม **Strict Server-Only Boundary Guardrail**: เลขาตอบเฉพาะข้อมูลและกฎเซิร์ฟเวอร์อย่างแม่นยำ และปฏิเสธการคุยเล่นนอกเรื่องอย่างสุภาพ
- **Hana Casual AI อิสระ**:
  - Hana ในห้อง `/setroomai` กลับมาคุยเล่นเป็นธรรมชาติในฐานะเด็กสาวมัธยมปลายร่าเริง โดยไม่ถูกรบกวนด้วยข้อมูลแอดมินเซิร์ฟเวอร์
- **ระบบอ่านออกเสียงในห้องเสียง (TTS)**:
  - เพิ่มคำสั่ง `/tts` ให้บอทเข้าห้องเสียงเพื่ออ่านข้อความแชตแบบเรียลไทม์ และ `/leave` เพื่อออกจากห้องเสียง
  - กรองแท็กผู้ใช้, แท็กยศ, แท็กห้อง, และลิงก์ URL อัตโนมัติ เพื่อเสียงอ่านที่ลื่นไหล
  - ระบบ Spam Cooldown 1.5 วินาที ป้องกันเสียงพูดซ้อนทับกัน
  - ตัดการเชื่อมต่ออัตโนมัติเมื่อไม่มีผู้ใช้อยู่ในห้องเสียง

## HanaBot v1.4.1 (beta) — 28 กันยายน 2026

- ปรับปรุงฐานข้อมูล SQLite ภายในเครื่อง พร้อมเข้ารหัส API key และ backup หมุนเวียนสูงสุด 3 ชุด
- ถอดระบบ Hana ทักก่อนออกทั้งหมด เพื่อลดการรบกวนสมาชิก
- ปรับ Hana ให้อ่านบริบทก่อนหน้าก่อนตีความข้อความกำกวม
- กันการอ้างว่าส่งรูปหรือแนบรูปโดยไม่มีผลลัพธ์จากระบบ
- เพิ่ม `/travelphoto` และการใช้งานผ่าน User Install/DM
- เพิ่ม `shrug`, `welcome`, `givegift`, `fistbump` และ `dance` ใน `/act` หรือ `/actwith` ตามประเภท
- `/act` และ `/actwith` ดึง Anime GIF ใหม่จากต้นทางทุกครั้ง
