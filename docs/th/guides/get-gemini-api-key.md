# วิธีรับ Gemini API key

คู่มือนี้ใช้สร้าง Google Gemini API key ของคุณเองเพื่อนำไปใช้กับ **โต๊ะเลขาประจำเซิร์ฟเวอร์ (`/hanacontext`)** หรือ **ระบบตัวละคร NPC (`/npc`)** ใช้เวลาเพียง 2–3 นาที

> ⚠️ **คำเตือนความปลอดภัย:** API key เปรียบเหมือนรหัสผ่าน ห้ามส่งในห้องแชต ห้ามเปิดเผยแก่ผู้อื่น และอย่าถ่ายภาพหน้าจอที่เห็นคีย์เต็ม หากเผลอเปิดเผย ให้เข้าไปลบคีย์นั้นใน Google AI Studio แล้วสร้างใหม่ทันที

---

## 1. เปิด Google AI Studio

เข้าเว็บไซต์ [Google AI Studio](https://aistudio.google.com/welcome) แล้วเข้าสู่ระบบด้วยบัญชี Google ของคุณ

หากเป็นการเข้าใช้งานครั้งแรก ให้กด **Get started** และยอมรับเงื่อนไขการใช้งานของ Google ก่อนดำเนินการต่อ

![ปุ่ม Get started บน Google AI Studio](../.gitbook/assets/gemini-api-key-01-get-started.png)

---

## 2. เปิดหน้า API Keys

เมื่อเข้าสู่หน้า AI Studio Dashboard เรียบร้อยแล้ว ให้คลิกที่ไอคอนรูปกุญแจ **API Keys** บริเวณแถบเมนูด้านซ้าย

![ไอคอนรูปกุญแจสำหรับเปิดหน้า API Keys](../.gitbook/assets/gemini-api-key-02-menu.png)

---

## 3. สร้างคีย์ใหม่

กดปุ่ม **Create API Key**

![ปุ่ม Create API Key](../.gitbook/assets/gemini-api-key-03-create.png)

- สำหรับผู้ใช้ใหม่ Google อาจมีโปรเจกต์และคีย์เริ่มต้นเตรียมไว้ให้อยู่แล้ว สามารถคัดลอกคีย์นั้นมาใช้ได้เลย
- หากระบบให้เลือกโปรเจกต์ ให้เลือกโปรเจกต์ Google Cloud เดิมที่มีอยู่ หรือกดสร้างโปรเจกต์ใหม่สำหรับ Hana
- เมื่อคีย์สร้างเสร็จ ให้กดไอคอน **Copy** เพื่อคัดลอกคีย์เก็บไว้ชั่วคราว

---

## 4. นำคีย์ไปใส่ใน Hana

### สำหรับโต๊ะเลขาประจำเซิร์ฟเวอร์ (`/hanacontext`)
1. เข้า Discord แล้วพิมพ์คำสั่ง `/hanacontext` ในเซิร์ฟเวอร์ของคุณ
2. เลือกห้องประจำที่ต้องการให้เลขาอยู่จาก `ChannelSelectMenu`
3. กดปุ่ม **ตั้งค่าเลขา / แก้ไขข้อมูล**
4. วาง API Key ของคุณลงในช่อง **Gemini API Key** แล้วกดยืนยัน
5. ระบบจะทดสอบคีย์และพร้อมตอบคำถามเกี่ยวกับเซิร์ฟเวอร์ทันที โดยไม่กินโควตาบอทส่วนกลาง

### สำหรับตัวละคร NPC (`/npc`)
- ระบบ NPC สามารถดึงคีย์ API จากที่เซิร์ฟเวอร์กำหนดไว้ หรือใช้คีย์ส่วนบุคคลตามที่ระบบเปิดให้ เพื่อให้ตัวละครโรลเพลย์ตอบกลับได้อย่างต่อเนื่องและราบรื่น

---

## ข้อควรทราบและการแก้ปัญหา

- บัญชี Google Workspace ของโรงเรียนหรือองค์กรอาจถูกปิดกั้นการสร้าง API Key แนะนำให้ใช้บัญชี Google ส่วนบุคคล
- API Key ทั้งหมดที่ใส่ลงใน Hana จะได้รับการ **เข้ารหัสอย่างปลอดภัยด้วยมาตรฐาน AES-256-GCM** ก่อนบันทึก และจะไม่มีการนำไปแสดงในบันทึกระบบ (Logs) หรือเปิดเผยต่อสาธารณะ
- ดูคู่มืออย่างเป็นทางการจาก Google: [เริ่มต้นใช้งาน Gemini API](https://ai.google.dev/gemini-api/docs/get-started) · [การจัดการความปลอดภัย API key](https://ai.google.dev/gemini-api/docs/api-key)
