# ความเป็นส่วนตัวและเงื่อนไข

## ข้อมูลที่ไม่ควรใส่

เพื่อความปลอดภัยและความเป็นส่วนตัวของผู้ใช้ อย่าส่งหรือบันทึกข้อมูลต่อไปนี้ใน Hana:

- ที่อยู่ พิกัดที่อยู่อาศัย หรือสถานที่ทำงาน
- เบอร์โทรศัพท์ อีเมลส่วนบุคคล หรือรหัสผ่าน
- ข้อมูลบัตรเครดิต บัญชีธนาคาร หรือข้อมูลทางการเงิน
- บัตรประชาชน หนังสือเดินทาง หรือเอกสารยืนยันตัวตน
- ข้อมูลสุขภาพ ประวัติการรักษา หรือความลับของผู้อื่น

หากต้องการให้ Hana หรือตัวละครจำชื่อเล่น ให้ระบุเพียงชื่อเล่น อายุ หรือวันสำคัญทั่วไปก็เพียงพอ

---

## สิ่งที่ Hana ไม่ทำ

- ไม่สุ่มแท็กทักหาสมาชิกก่อนเพื่อไม่รบกวนการสนทนา
- ไม่เดาอายุ ข้อมูลส่วนตัว หรือเพศสภาพจากชื่อ รูปโปรไฟล์ หรือข้อความ
- ไม่อ้างว่าส่งรูปภาพหรือทำกิจกรรมสำเร็จ หากระบบภายนอกยังไม่ยืนยันผลลัพธ์
- ไม่เริ่มบทโรแมนติกเชิงชู้สาว โดย Hana จะรักษาความสัมพันธ์แบบเพื่อนสนิทเสมอ

> **หมายเหตุ:** ข้อจำกัดความเป็นเพื่อนสนิทข้างต้นเป็นบุคลิกเฉพาะตัวของ Hana สำหรับตัวละครโรลเพลย์ที่สร้างในระบบ `/npc` จะแสดงบทบาทตามการตั้งค่าของผู้สร้าง แต่ยังต้องอยู่ภายใต้กฎหมาย กฎความปลอดภัยของ Discord และ Safety Filters ของผู้ให้บริการ AI

## ความปลอดภัยของ API Key (สำหรับ `/hanacontext` และ `/npc`)

- ใส่ API Key (Gemini หรือ OpenRouter) ผ่านแบบฟอร์ม Modal ของคำสั่งเท่านั้น ห้ามพิมพ์ลงในแชตปกติ
- คีย์ทั้งหมดจะถูก **เข้ารหัสด้วยมาตรฐาน AES-256-GCM** ก่อนบันทึกลงในฐานข้อมูล SQLite ภายในเครื่องบอท
- ไม่มีการนำ API Key ไปแสดงในบันทึกระบบ (Logs), ไม่เปิดเผยต่อสมาชิกอื่น, และไม่มีการส่งต่อให้บุคคลภายนอก
- บอทมีระบบสำรองข้อมูลฐานข้อมูลหมุนเวียนสูงสุด 3 ชุดเพื่อความปลอดภัยของระบบ
