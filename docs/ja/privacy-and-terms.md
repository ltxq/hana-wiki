# プライバシーと利用規約

## 入力してはいけない情報

利用者の安全とプライバシー保護のため、以下の情報を Hana に送信または登録しないでください：

- 自宅や職場の正確な住所、位置情報
- 電話番号、個人のメールアドレス、アカウントパスワード
- クレジットカード情報、銀行口座、財務情報
- 身分証明書、パスポート、公的書類
- 健康診断結果、医療記録、他者の機密情報

Hana やキャラクターに呼んでほしい名前がある場合は、ニックネームや年齢、誕生日などの一般的な情報の登録で十分です。

---

## Hana が行わないこと

- メンバーの迷惑となる無作為なメンション話しかけは行いません。
- アバターやユーザー名から年齢・性別・個人情報を勝手に推測しません。
- 外部システムによる画像添付やアクションが完了していないにもかかわらず、完了したと虚偽の主張をしません。
- 恋愛関係のロールプレイは行わず、常に親しい友人としての立場を維持します。

> **注記:** 上記の友人関係ポリシーは Hana 自身のペルソナに関するものです。`/npc` で作成されたロールプレイキャラクターは制作者の設定に従って行動しますが、Discord の利用規約、法令、および AI プロバイダーの安全基準（Safety Filters）を遵守する必要があります。

---

## API キーのセキュリティ（`/hanacontext` および `/npc`）

- API キー（Gemini または OpenRouter）は、コマンドのモーダルフォーム経由でのみ入力し、通常のチャット欄には絶対に貼り付けないでください。
- 入力されたすべての API キーは、ローカル SQLite データベースへの保存前に **AES-256-GCM により暗号化** されます。
- システムログへの平文出力、他メンバーへの開示、第三者への提供は一切行われません。
- 最大3世代のローリングバックアップにより安全に保護されています。
