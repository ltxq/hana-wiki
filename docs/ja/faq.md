# よくある質問（FAQ）

## Hana が応答しない時はどうすればいいですか？

そのチャンネルで `/setroomai` が実行されているか、また Bot に `View Channel`、`Send Messages`、`Read Message History` の権限が付与されているか確認してください。対応言語はタイ語、英語、日本語です。

---

## NPC の作成や会話はどう行いますか？

チャンネルで `/npc` を実行して **➕ NPCを作成** を押し、モーダルフォームで 3 項目（名前、性格設定、オープニング挨拶）を入力して作成します。それ以外の操作はすべて同じパネルのボタンから行えます。作成後の対話方法は以下の 2 通りです：
1. NPC のメッセージに **直接返信（リプライ）** する。
2. チャット内で **NPC の名前を含めて発言** する。

---

## サーバー秘書デスク（`/hanacontext`）と通常の Hana AI ルームの違いは何ですか？

- **サーバー専属秘書デスク（`/hanacontext`）**: サーバーの案内所として機能し、規約、案内、イベント、ロール情報のみを専門に回答します。厳格なガードレールが設定されており、無関係な雑談は丁寧に辞退します。
- **Hana AI ルーム（`/setroomai`）**: 管理規則から解放された Hana が、ゲーム（Splatoon）やお菓子、日常の話題について楽しくおしゃべりする親しみやすい友達としての部屋です。

---

## 音声読み上げ（TTS）はどのように使いますか？

ボイスチャンネルに参加した状態で、読み上げ対象のテキストチャンネルで `/tts` を実行します。退出させたい場合は `/leave` を実行するか、ボイスチャンネルのメンバー全員が退出すると自動的に切断されます。

---

## 登録した API キーの安全性はどうなっていますか？

極めて安全です。`/hanacontext` や設定から登録された API キー（Gemini / OpenRouter）は、データベース保存前に **AES-256-GCM** により強力に暗号化されます。ログに平文で出力されたり外部へ開示されることはありません。

---

## なぜ Hana はすぐに答えず質問を返してくることがあるのですか？

発言内容が曖昧な場合、Hana は誤った推測やハルシネーションを防ぐために、直前の会話文脈を確認した上で短く聞き返す設計になっています。

---

## `/travelphoto` で Missing Permissions と出るのはなぜですか？

Discord 側で該当チャンネルにおける Hana の `Embed Links`（埋め込みリンク）権限が無効になっている可能性があります。権限を許可してください。

---

## サーバーをまたいで記憶は引き継がれますか？

いいえ。メモリーは短期間のみで、常にサーバー単位に保存されます。サーバー間共有はできません。データは `/settings` → データ から削除できます。
