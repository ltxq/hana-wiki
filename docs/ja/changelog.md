# 更新履歴

## HanaBot v1.5.2 — 2026年11月25日

- **⚙️ コマンドの整理（ベータ期間中）**:
  - `/settingai` を **`/settings`** に改名。言語選択は**最初のページ**へ移動し、メモリーが短期化されたため「メモリーを見る」ボタンを削除しました。
  - `/premium` を削除し、ベータ期間中はすべての機能を無料化。`/statusai`、`/hanainsights`、秘書デスクから Premium のロック文言とリンクも削除しました。
  - コマンド説明から「(ฟรี)」を削除しました。
  - `/statusai` は必要な項目だけ表示するようになりました：日本時間、いまの活動、場所、天気、服装、気分、健康、興味、今日のイベント（性格・まとめ・エネルギー・Discord ステータス・大学カレンダーは削除）。
  - `common.status:` や `settings.memory.title:` のような未翻訳キーが表示されるバグを修正しました。
  - 秘書設定は**モデル選択メニュー**に変わり（provider/model の手入力不要）、API キー入力欄も削除。キーは `/admin` のサーバー共通キーを一度設定するだけです。
  - Gemini の 503 エラーは、生の JSON ではなく Hana が返答できないときのような短いタイ語メッセージに置き換えました（秘書・NPC・RoomAI）。
  - **サーバー共通の AI モデル**を `/admin` のボタンまたは `/admin model:` のオートコンプリート検索で設定可能に。ピッカーは **Gemini** と **OpenRouter** のボタンに分離し、Gemini は 3.1 Flash 以降のみ（古い 2.x を削除）、OpenRouter は無料モデルを先頭に表示。ページ送り・キーワード検索対応で、秘書と NPC は既定値を使いつつ個別変更できます。
  - **Server Admin Hub** の表示を見やすく整理（キー / モデル / システム状態のセクションと余白、ボタンは短い3行）。
  - **プロンプトのトークン最適化**: 父親キャラを Discord User ID で切り替える別プロンプトに分離。オーナーだけがその分のトークンを消費し、一般メンバーは Sky/父親の文脈のない淡白な「友人」プロンプトを受け取るため、「พ่อ」と呼ばれる誤りも解消。
  - **天気の一貫性**: 確認済みの札幌の天気を毎リクエストに短く付与（詳細は質問時のみ）。「初雪」ステータスは日付ではなく天気 API が実際に雪を報告した場合のみ有効。
  - プロンプト組み立てを `System/roomai-prompt.js` に分離し、実テスト（オーナー/一般のプロンプト差・天気の埋め込み・天気連動イベント）を追加。
  - **3言語対応を拡大**: `/statusai`、`/guildbook`、`/hanainsights`、Admin Hub、モデル選択パネル、秘書設定フローが `/settings` の言語に追従するようになりました。
  - **OpenRouter のモデル選択を大幅拡張**: OpenRouter のライブ一覧から数百のチャットモデルを取得（利用不可・期限切れ・非チャットを除外）し、検索・ページ送りに対応。「無料」という表現は削除しました（期間限定の無料公開は変動するため）。
  - **サーバー人数条件を撤廃**: 小規模サーバーに追加しても拒否通知や自動退出は行わず、サーバー名・オーナー・人数などの情報をログとして保存するだけになりました。
  - **睡眠中も他のメンバーに邪魔せず会話**: Hana が寝ている時に2回続けてメッセージを送ると、その人だけに「会話を続けますか？」と非表示メッセージが表示され、✅ はい / ❌ いいえ ボタンが出ます。
  - **`/settings` のトグルを変更**: 「スケジュール全体を無視」から**「睡眠時間だけスキップ」**に。他のアクティビティはそのままで、このボタンと非表示メッセージのボタンは常に同期します。
  - 会話に戻った時の「หายไปไหนมาเนี่ย」という挨拶を削除しました。
  - **秘書が通常チャットに割り込まなくなりました**: 設定したデスク用チャンネル（そのスレッド含む）か、秘書のメッセージに返信した時だけ応答します。別の部屋で「เลขา」と書くだけでは呼び出されません。
- **🎭 `/npc` が単一のボタンパネルになりました**:
  - 5つのサブコマンド（`create` / `list` / `move` / `edit` / `delete`）を、秘書デスクのような使いやすいボタンハブを開く `/npc` 1つに統合しました。
  - 作成、絞り込み（すべて/自分の）、メニューからのキャラクター選択、モデル変更、プロフィール・キー・チャンネル編集、削除まで、IDやコマンド名を打たずに操作できます。
  - パネル全体がタイ語・英語・日本語に対応。キャラクターのキーをクリアするとサーバー共通キーへ正しくフォールバックします。
- **🔒 メモリーはサーバーごとに分離されました**:
  - メモリーは **Discord User ID + Server ID** ごとに保存されます。あるサーバーの会話が別のサーバーに混ざることはありません。
  - それまでの全サーバー共通のメモリーは state に別途保持されていますが、移行ボタンはメモリーパネルと一緒に削除されました。
  - 要約ジョブもユーザーごと・サーバーごとに区分され、あるサーバーが別のサーバーを上書きすることがなくなりました。
- **🌐 設定パネルが言語に従うようになりました**:
  - 言語選択は **`/settings` の最初のページ**にあります（タイ語・英語・日本語、または会話している言語に合わせる「自動」）。
  - 設定、メモリー、個人情報、プロフィールの各パネルが、選択した言語で表示されます。
- **🔑 機能ごとの API キー**:
  - サーバー秘書のセットアップフォームに sec_keys 欄を追加し、専用の API キーを設定できるようにしました（空欄ならサーバーの共通キーを使います）。
  - NPC は管理パネルの **API キーを設定** ボタンから独自のキーを設定できます。
  - NPC パネルは 2 段のボタン行に分け、NPC 専用キーと共通キーの両方に手が届くようにしました。
- **ドキュメントとポリシーの更新**: メモリーのサーバー単位の分離がコードと一致するよう、プライバシーポリシーを更新しました。

## HanaBot v1.5.1 — 2026年11月25日

- **3言語対応（タイ語・英語・日本語）**:
  - UI と設定パネルの文言を `locales/` に移し、言語ごとに個別に編集できるようにしました。
  - AIクォータやキュー満杯のメッセージが、常にタイ語ではなく**相手の言語**で返答するようになりました。
  - 秘書デスクの範囲外の辞退が、常にタイ語ではなく**質問者の言語**になりました。
  - メモリー検索とスプラトゥーンの質問で日本語に対応しました。
  - `/travelphoto` の補完で日本語・タイ語・英語の都道府県名から検索できます。
- **NPC と秘書が会話を記憶するように**:
  - NPC はあなたとの会話（キャラクターごと・ユーザーごと）を最大12往復まで記憶し、毎回の返答を忘れることがなくなりました。
  - 秘書デスクも同様に、話題を繰り返し説明せず続けて質問できます。
- **バグ修正**:
  - `/hanagame` のお絵かきの命题が実際に AI を呼ぶようになり、**クォータも正しく消費**します（従来はコードが死んだままで動いていませんでした）。
  - どのコードからも使われていない不要ファイル（GIFキャッシュ、Private AI のデータベース、バックアップモジュール）を削除しました。
- **ドキュメントとポリシーの更新**:
  - プライバシーポリシーと利用規約を実際に存在する機能に合わせて書き直しました（削除済みの Private AI と `/dmpanel` の記載を削除）。
  - **メモリーはサーバー横断（User ID 単位）で、関係性のみサーバー単位**であることを明記しました（コードと一致）。
  - NPC、秘書デスク、`/admin` コマンドの説明を案内に追加しました。

## HanaBot v1.5.0 — 2026年11月

- **NPC ロールプレイシステム（`/npc`）**:
  - 旧 Private AI を刷新し、Discord Webhook を用いた新 NPC アーキテクチャを導入。
  - 3項目の入力モーダル（`/npc create`）で簡単作成：キャラクター名、性格・プロンプト、オープニングの挨拶。
  - Webhook によるキャラクター固有のアイコンと名前での発言を実現。
  - NPC メッセージへの **直接返信（リプライ）** またはチャット内での **名前メンション** による自然なマルチターン対話。
  - 充実した管理コマンド群：`/npc list`、`/npc move`、`/npc edit`、`/npc delete`。
  - 独自 API キー（Gemini / OpenRouter）およびキーローテーションに対応し、Bot 本体のクォータを非消費。
- **サーバー専属秘書デスク（`/hanacontext`）**:
  - サーバーの規約・案内業務と、Hana 本来の気さくな日常雑談ペルソナを完全分離。
  - Discord の `ChannelSelectMenu` を導入し、1クリックでの配属チャンネル選択を実現。
  - 秘書名、サーバー規約コンテキスト、管理者独自 API キーを設定するモーダルを新設。
  - **厳格なサーバー専用境界ガードレール（Strict Guardrails）**: 規約、ロール、チャンネル情報、お知らせの案内に厳密に限定。雑談や無関係な質問は丁寧に断り適切なチャンネルへ誘導。
- **Hana 日常会話の独立化**:
  - `/setroomai` での Hana は、管理業務の縛りから解放され、親しみやすい女子高生として自由に楽しく雑談。
- **音声読み上げシステム（TTS）**:
  - ボイスチャンネルでメッセージを読み上げる `/tts` および退出用の `/leave` を新設。
  - ユーザーや役職のメンション、チャンネルタグ、URL を自動除去するテキストサニタイズ処理。
  - 音声の重なりや途切れを防ぐ 1.5 秒のスパム防止クールダウン制御。
  - ボイスチャンネルが無人になった際の自動退出（Auto-Leave）機能。

## HanaBot v1.4.1 (beta) — 2026年9月28日

- データベースをローカル SQLite に移行。AES-256-GCM 暗号化と最大3世代のローリングバックアップを導入。
- メンバーへの無作為なメンション話しかけ機能を完全撤廃。
- 曖昧な発言に対して過去の文脈を丁寧に参照するよう改善。
- 写真送信に失敗した場合の誤認発言を防止。
- `/travelphoto` の追加および User Install / DM での利用に対応。
- アクションコマンドに `shrug`, `welcome`, `givegift`, `fistbump`, `dance` を追加。
- `/act` および `/actwith` において、常に最新の Anime GIF を配信元から直接取得するよう改善。
