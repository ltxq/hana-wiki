# コマンド一覧

Hana の全スラッシュコマンドをカテゴリ別にまとめたリファレンスです：

---

## 💬 Hana AI と個別設定

Hana との日常会話、時間割ルーチンの確認、個人の各種設定を行います。

| コマンド | 説明 |
| :--- | :--- |
| `/setroomai` | 現在のチャンネルで Hana AI との雑談を有効化 |
| `/unsetroomai` | 現在のチャンネルの Hana AI 雑談を無効化 |
| `/guildbook` | Discord 上で各種機能と会話方法のガイドを表示 |
| `/statusai` | 日本時間に基づく Hana の活動状況やステータスを表示 |
| `/settings` | 個人設定パネル — 最初のページで言語を選択、返信・時刻・プロフィール・データ |
| `/profile` | 自身のプロフィールおよび Hana との親愛度レベルを表示 |

👉 詳しくはこちら: [AI と各種設定](ai-and-settings.md)

---

## 🎭 NPC ロールプレイシステム

専用のアイコンと名前を持つ Webhook を介して応答するロールプレイキャラクターを作成・管理します。

| コマンド | 説明 |
| :--- | :--- |
| `/npc` | 1つのボタンパネルで全部操作: 作成、一覧/絞り込み、管理（モデル・プロフィール・キー・チャンネル）、削除。サブコマンドを覚える必要はありません。 |

👉 詳しくはこちら: [NPC ロールプレイシステム](npc-roleplay.md)

---

## 🏢 サーバー管理＆秘書デスク

サーバー管理者向けの案内・ルール設定機能です。

| コマンド | 説明 |
| :--- | :--- |
| `/hanacontext` | サーバー規則の管理および **サーバー専属秘書デスク** の設定（1クリック部屋選択、`/secretary` という別名もあります） |
| `/admin` | AIシステム管理ハブ。サーバーの **共通APIキー** を設定します（モデレーター専用） |
| `/hanainsights` | 今週の AI クォータと全員に開いている機能を表示（すべて無料） |

👉 詳しくはこちら: [サーバー管理者ガイド＆秘書デスク](../roomai-and-permissions.md)

---

## 🔊 音声読み上げシステム（TTS）

Hana をボイスチャンネルに呼び出し、チャットメッセージを音声で読み上げます。

| コマンド | 説明 |
| :--- | :--- |
| `/tts` | 参加中のボイスチャンネルに Hana を呼び出して読み上げを開始 |
| `/leave` | Hana をボイスチャンネルから即座に退出させる |

👉 詳しくはこちら: [音声読み上げシステム（TTS）](tts.md)

---

| コマンド | 説明 |

👉 詳しくはこちら: [日本の旅行写真](travel-photo.md)

## 🎮 Fun と Anime GIF

| コマンド | 説明 |
| :--- | :--- |
| `/act` | 自分自身のアクションを表す Anime GIF を送信（ダンス、手振り、泣くなど） |
| `/actwith` | 相手と一緒に楽しむ Anime GIF を送信（プレゼント機能 `givegift` 含む） |
| `/hanagame` | Hana のミニゲームパネルを起動 |

👉 詳しくはこちら: [Fun と Anime GIF](fun-and-actions.md)
