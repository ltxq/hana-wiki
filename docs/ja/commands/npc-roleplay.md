# NPC ロールプレイシステム

`/npc` は、Discord Webhook を活用したサーバー専用のロールプレイキャラクター管理システムです。キャラクターごとに独自の名前とアイコン画像で返信するため、まるで本物のメンバーがチャットに参加しているかのような臨場感を提供します。

---

## 主な特徴

- **Webhook による個別表示**: キャラクター専用のアイコン画像と表示名でメッセージを自動送信。
- **3項目の簡単作成モーダル（`/npc create`）**: 「NPCの名前」「性格・プロンプト」「オープニングの挨拶」を入力するだけで即座に Webhook が作成され、挨拶メッセージが投稿されます。
- **自然な対話スタイル**: NPC のメッセージへの**直接返信（リプライ）**、またはチャット内で**名前を呼ぶ**ことでスムーズに対話可能。
- **会話を実際に記憶**: 各キャラクターはあなたとの会話（キャラクターごと・ユーザーごとに別）を最大12往復まで記憶するので、毎回のやり取りを忘れることなく会話を続けられます。
- **モデルの選択**: Gemini、OpenRouter（DeepSeek・GPT・Claudeなど）、または任意の Provider と Model を自分で指定できます。
- **独立したクォータ管理**: ユーザーまたはサーバー管理者自身の API キー（Gemini / OpenRouter）およびキーローテーションに対応。Bot 本体の共有クォータを浪費しません。
- **通常の Hana との完全な分離**: Hana は通常の `/setroomai` チャンネルで気さくな女子高生として会話を続け、NPC は各自独立した設定に従って振る舞います。

---

## コマンド一覧（`/npc`）

| サブコマンド | 説明 | 必要権限 |
| :--- | :--- | :--- |
| `/npc create` | 現在のチャンネルに新しい NPC を作成するモーダルを開く | メンバー一般 / サーバー設定による |
| `/npc list` | サーバー内の全 NPC リスト（ID・配置チャンネルなど）を表示 | 全員 |
| `/npc move` | NPC の配属チャンネルを変更（未指定で全室対応） | NPC 所有者 / 管理者 |
| `/npc edit` | NPC の名前、性格設定、アイコン画像を編集 | NPC 所有者 / 管理者 |
| `/npc delete` | NPC を削除し、関連する Webhook をクリーンに破棄 | NPC 所有者 / 管理者 |

---

## NPC の作成方法（`/npc create`）

1. NPC を登場させたいチャンネルで `/npc create` を実行します。
2. 入力フォーム（モーダル）に以下の 3 項目を入力します：
   - **NPC の名前**: Webhook に表示されるキャラクター名（例: `ヤミ`, `アイコ先生`, `騎士アーサー`）
   - **性格 / プロンプト**: キャラクターの役割、背景、口調、行動方針、発言制限など
   - **オープニングの挨拶**: 作成完了時に NPC がチャンネルへ最初に投稿するメッセージ
3. *(任意)* アイコン画像ファイルの添付、または画像 URL を指定します。
4. 送信すると、Bot が自動的に Discord Webhook を発行し、最初の挨拶を投稿します。

---

## NPC との会話方法

メンバーは以下の 2 つの方法で簡単に NPC と対話できます：

### 1. メッセージへ返信（リプライ）
NPC が送信したメッセージに対して Discord の **返信（Reply）** 機能を使って返信します。Bot が直前の会話文脈を参照し、自然な対話を続けます。

### 2. 名前を呼ぶ（名前メンション）
メッセージの中に **NPC の名前** を含めて投稿します。例：
```text
ヤミ、今日の数学の宿題はもう終わった？
```
そのチャンネルにいる該当 NPC が自動的に反応し、キャラクターとして返答します。

## NPC の管理

### NPC リストの確認（`/npc list`）
`/npc list` コマンドで、サーバー内の NPC 一覧を確認できます：
- キャラクター ID（編集や削除、移動に使用）
- キャラクター名
- 配属チャンネル
- 作成者

### チャンネルの移動（`/npc move`）
```text
/npc move id:npc_xxxxxx channel:#roleplay-room
```
`channel` オプションを空欄にすると、サーバー内の対応する全チャンネルで応答可能になります。

### 設定の編集（`/npc edit`）
```text
/npc edit id:npc_xxxxxx
```
名前、プロンプト、アイコン画像の更新フォームが開きます。管理パネルから **AI モデル** の選択と、キャラクター固有の **API キー** 設定も行えます。

### キャラクターの削除（`/npc delete`）
```text
/npc delete id:npc_xxxxxx
```
キャラクターデータと保存済みの会話履歴を削除し、チャンネルに作成されていた Webhook も安全に削除されます。

## API キーの設定

キャラクターごとに独自のキーを設定すれば、Bot の共通クォータを消費せずに済みます：

1. `/npc edit id:npc_xxxxxx` を実行
2. **API キーを設定** ボタンを押す
3. 1行に1つずつキーを貼り付けて保存

レート制限にかかったキーには Hana が自動的に切り替えます。他のメンバーのキーや Bot の共通キーに勝手に差し替えることはありません。使えるキーが無ければ、キャラクターの所有者に通知されます。

> サーバーモデレーターは `/admin` でサーバー全体の共通キーを設定できます。キャラクターに固有のキーがない場合はそちらが使われます。

---

## 必要な Discord 権限

NPC システムを正常に動作させるには、チャンネル内で Bot に以下の権限が必要です：
- `Manage Webhooks`（Webhook の管理 - NPC メッセージの送信に必須）
- `View Channel`（チャンネルを見る）
- `Send Messages`（メッセージを送信）
- `Read Message History`（メッセージ履歴を読む）
