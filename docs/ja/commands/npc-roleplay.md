# NPC ロールプレイシステム

`/npc` は、Discord Webhook を活用したサーバー専用のロールプレイキャラクター管理システムです。キャラクターごとに独自の名前とアイコン画像で返信するため、まるで本物のメンバーがチャットに参加しているかのような臨場感を提供します。

> **v1.5.2 の更新:** `/npc` は**ボタンパネルを開く単一コマンド**になりました。以前のサブコマンド（`create` / `list` / `move` / `edit` / `delete`）はすべてボタンに移行しています。秘書デスク（`/secretary`）と同じ感覚で使えます。

---

## 主な特徴

- **1つのコマンドでボタン操作だけ**: `/npc` を打てば、あとはパネルのボタンとメニューを選ぶだけ。サブコマンド名やキャラクターIDを覚える必要はありません。
- **Webhook による個別表示**: キャラクター専用のアイコン画像と表示名でメッセージを自動送信。
- **3項目の簡単作成**: **➕ NPCを作成** を押し、「名前」「性格・プロンプト」「オープニングの挨拶」を入力するだけで即座に Webhook が作成され、挨拶が投稿されます。
- **自然な対話スタイル**: NPC のメッセージへの**直接返信（リプライ）**、またはチャット内で**名前を呼ぶ**ことで対話できます。
- **会話を実際に記憶**: キャラクターごと・ユーザーごとに最大12往復を記憶し、6時間沈黙すると忘れます。
- **モデルの選択**: 管理画面のメニューから Gemini、OpenRouter（DeepSeek・GPT・Claude）、またはカスタム provider/model に即時切り替え。
- **3言語対応**: `/settingai` で設定した言語（タイ語・英語・日本語）に合わせてパネル全体が表示されます。
- **独立したクォータ管理**: キャラクター専用の API キーを優先し、無ければ `/admin` のサーバー共通キーを使用。Bot 本体のクォータを浪費しません。
- **通常の Hana との完全な分離**: Hana は `/setroomai` チャンネルで気さくな女子高生として会話を続け、NPC は独立して振る舞います。

## ハブを開く（`/npc`）

サーバー内の任意のチャンネルで `/npc` を実行すると、Hana が**あなたにだけ見える（エフェメラル）**パネルを表示します:

- サーバー内のキャラクター数と、あなたのキャラクター数
- サーバー共通 API キーの状態
- キャラクターのプレビュー一覧（名前・常駐チャンネル・モデル・キーの種類）
- 管理画面へ直接移動できる**キャラクター選択メニュー**

誰でもハブを開けます。管理者向けショートカット（**共通キー**、**秘書デスク**）は、チャンネル/サーバー管理権限を持つメンバーにのみ表示されます。

### ハブのボタン

| ボタン | 動作 |
| :--- | :--- |
| ➕ **NPCを作成** | 現在のチャンネルにキャラクターを作る3項目モーダルを開く |
| 🎭 **すべて** / 👤 **自分の** | 一覧とメニューを全キャラクター / 自分のものだけに絞り込む |
| ❓ **使い方** | パネル内に短いガイドを表示 |
| 👑 **共通キー** | `/admin` へ移動（管理者のみ） |
| 👩‍💼 **秘書デスク** | `/secretary` へ移動（管理者のみ） |
| 🔄 **更新** | 変更後にパネルを再読み込み |

## キャラクターの作成

1. `/npc` を実行します。
2. **➕ NPCを作成** を押します。
3. モーダルに入力します:
   - **NPCの名前** — Webhook の表示名（例: `Yami`、`さくら先生`、`Knight Arthur`）
   - **性格 / キャラクター** — 役柄、背景、話し方、振る舞いの制約
   - **第一声 / 挨拶** — 作成直後にチャンネルへ投稿される最初のメッセージ
4. 送信すると Webhook が作成され、第一声が投稿され、キャラクターIDがエフェメラルな確認メッセージに表示されます。

## NPC との会話

### 1. 直接返信（リプライ）
NPC のメッセージに**リプライ**して返信します。そのキャラクターの会話履歴を使って文脈に沿って返答します。

### 2. 名前で呼ぶ
チャンネル内でキャラクターの名前を文中に書きます:
```text
やあ Yami、今日の数学の宿題は終わった？
```
そのチャンネルに常駐している同名の NPC がキャラクターとして返信します。

## キャラクターの管理

ハブの選択メニューからキャラクターを選ぶと、管理パネルが開きます:

- **モデル選択メニュー** — プロバイダー/モデルを即時変更。**⚙️ カスタム** で `provider:model` を自分で入力可能。
- 📝 **プロフィール編集** — 名前、性格、第一声、アバターURLを変更。
- 🔑 **APIキー設定** — 専用キーの設定・削除。
- 📍 **チャンネルを変更** — テキストチャンネルを選択、または **🌐 全チャンネル (Global)** を押す。
- 🗑️ **削除** — 確認後にキャラクターを削除。
- 📋 **ハブに戻る** — メインパネルへ戻る。

### API キーの設定

1. キャラクターの管理パネルを開く。
2. **🔑 APIキー設定** を押す。
3. 1行に1キー入力して保存。**空欄で保存するとキーが削除**され、`/admin` のサーバー共通キーにフォールバックします。

キーがレート制限に達すると自動でローテーションします。キャラクターが他のメンバーのキーを使うことはなく、Bot の共通キーは管理者が設定した最終フォールバックとしてのみ使われます。

## 必要な Discord 権限

NPC システムを正常に動作させるには、Bot に以下の権限が必要です:
- `Manage Webhooks`（Webhook の管理 — キャラクター名でのメッセージ作成・送信に必須）
- `View Channel`（チャンネルの閲覧）
- `Send Messages`（メッセージの送信）
- `Read Message History`（履歴の閲覧）
