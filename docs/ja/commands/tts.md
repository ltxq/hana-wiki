# 音声読み上げシステム（TTS）

Hana の Text-to-Speech（TTS）機能により、Bot がボイスチャンネルに参加してテキストチャットのメッセージをリアルタイムで読み上げます。

---

## コマンド一覧

| コマンド | 説明 | 利用対象 |
| :--- | :--- | :--- |
| `/tts` | あなたが参加しているボイスチャンネルに Hana を呼び出し、現在のテキストチャンネルの読み上げを開始 | サーバー内の全メンバー |
| `/leave` | Hana をボイスチャンネルから即座に退出させる | サーバー内の全メンバー |

---

## 主な特徴とクリーンアップ処理

### 1. 快適なテキスト自動整形（サニタイズ）
自然で聞き取りやすい読み上げを実現するため、以下の内容を自動でフィルタリングします：
- **ユーザー・役職メンションの除外**: `<@123456789>` や `<@&987654321>` などの数字列を読み上げずにスキップします。
- **チャンネルメンションの除外**: `<#channel>` のようなチャンネルリンクを除去します。
- **URL の自動スキップ**: `http://` や `https://` で始まるリンクアドレスは読み上げません。
- **カスタム絵文字の読み替え**: `<:smile:12345>` のような形式は「smile」という名前のみを読み上げます。

### 2. 1.5秒スパム防止クールダウン
連続してメッセージが投稿された場合でも音声が重なったり途切れたりしないよう、1.5秒のインターバル制御が施されています。

### 3. 自動退出機能（Auto-Leave）
ボイスチャンネル内のメンバーが全員退出すると、Hana は無人を検知して自動的に切断し、回線やリソースの消費を抑えます。

---

## 必要な Discord 権限

ボイスチャンネルで Hana が読み上げるには、以下の権限が必要です：
- `Connect`（接続）
- `Speak`（発言）
