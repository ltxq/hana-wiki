# AI と各種設定

サーバー内で独自のロールプレイキャラクターを作成・管理したい場合は、[`/npc`](npc-roleplay.md) ガイドをご覧ください。

---

## `/guildbook`

Discord 上で Hana との会話方法や利用可能な機能のガイドを開きます。

---

## `/statusai`

日本時間（JST）に基づく Hana の現在のアクティビティ（授業、部活、ゲームなど）や時間帯、Discord 上のステータスを確認できます。一部の詳しい情報は Hana Premium 特典です。

---

## `/settingai`

自分専用の設定パネルを開きます（他のメンバーには表示されません）：

- Hana 返信時のメンション通知の ON / OFF
- 現在のサーバーでの会話記憶の ON / OFF
- 許可した記憶の他サーバーとの共有設定
- 自身のタイムゾーン（時間帯）の設定
- プロフィール情報（ニックネーム、趣味、記念日など）の追加・編集・削除

> **注意事項:** 住所、電話番号、パスワード、クレジットカード情報などの機密情報は絶対に入力しないでください。ニックネームや好きなものの登録で十分です。

メンバーの迷惑にならないよう、Hana が無作為にメンションして話しかける機能は廃止されています。

---

## `/profile`

登録したプロフィールと、現在のサーバーにおける Hana との親愛度レベルを表示します。

### 親愛度レベル：

| スコア | 関係性 |
| :--- | :--- |
| 0–24 | 知人（Acquaintance） |
| 25–100 | よく話す仲（Regular Chat） |
| 101–300 | 友達（Friend） |
| 301–500 | 親友（Close Friend） |

> Hana は親しい友達としての立場を守り、恋愛関係のロールプレイには応じません。

---

## `/hanainsights`

現在のサーバーの AI クォータ残量、プラン階層、付与された権限を確認します。

---

## `/hanacontext` — サーバー管理者専用

サーバーコンテキスト管理および **サーバー専属秘書デスク（Dedicated Server Secretary）** を設定します。`ChannelSelectMenu` による1クリック部屋選択、サーバー規則のプロンプト注入、管理者独自 API キーによる完全自律稼働（Bot クォータ非消費）に対応しています。

詳細は [サーバー管理者ガイド＆秘書デスク](../roomai-and-permissions.md) をご覧ください。
