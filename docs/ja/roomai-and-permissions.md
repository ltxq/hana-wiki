# サーバー管理者ガイド＆秘書デスク

このページでは、Hana AI チャットルームの設定、`/hanacontext` を使ったサーバー専属秘書デスクの設定、および必要な Discord 権限について解説します。

---

## 1. Hana AI チャットルーム（`/setroomai`）

サーバー管理者が Hana をチャットルームに参加させたり終了させたりするためのコマンドです：

| コマンド | 説明 | 必要権限 |
| :--- | :--- | :--- |
| `/setroomai` | 現在のチャンネルで Hana AI を有効化（メンバーと自由雑談） | `Manage Channels` |
| `/unsetroomai` | 現在のチャンネルの Hana AI を無効化 | `Manage Channels` |
| `/guildbook` | Discord 上で Hana の機能ガイドを表示 | 全員 |

> **注記:** AI ルームの Hana は、Splatoon やお菓子、日本文化が大好きな明るい女子高生として会話します。サーバーの管理規則や案内業務とは完全に切り離されています。

---

## 2. サーバー専属秘書デスク（`/hanacontext`）

`/hanacontext` コマンドを使用すると、サーバーのルール説明、チャンネル案内、役職紹介、よくある質問に特化して回答する **サーバー専属秘書（Dedicated Server Secretary）** を設置できます。

### 秘書デスクの設定手順

1. `/hanacontext` を実行します（`Manage Guild` または管理者権限が必要）。
2. **1クリック配属チャンネル選択（`ChannelSelectMenu`）**: ドロップダウンメニューから秘書を常駐させたいチャンネルを1クリックで直接選択します（名前やIDの手入力不要）。
3. **「秘書設定 / 編集」** ボタンを押してモーダルフォームを開きます：
   - **秘書の名前**: 応答時に名乗る名前（例: `秘書サキ`, `案内窓口`）
   - **サーバーコンテキスト**: サーバーの利用規約、ルール、役職の説明、重要リンク、FAQ
   - **API キー（Gemini または OpenRouter）**: 管理者自身の API キーを登録します。Bot 本体の共有クォータを消費せず、安定した高速レスポンスを実現します。
   - **AI モデル**: 利用したいモデルを選択します。
4. 設定を保存すると、選択したチャンネルですぐに秘書デスクが稼働します。

### 厳格なサーバー専用境界ガードレール（Strict Guardrails）

サーバー専属秘書には厳格なプロンプトガードレールが設定されています：
- **サーバー関連の質問にのみ回答**: 規約、案内、イベント、ロール、チャンネル情報にのみ特化して正確に回答します。
- **無関係な雑談の丁寧な辞退**: 天気、冗談、個人的な雑談、一般的なロールプレイなどの話題に対しては、丁寧に辞退した上でサーバーの話題または通常の Hana チャット（`/setroomai`）へ案内します。
- **書面た言語で常に回答**: タイ語・英語・日本語のどれで書いても、その言語で返答します。辞退の言葉も同じ言語です。

### 会話の記憶

秘書との会話は最大12往復（サーバーごと・メンバーごとに別）で記憶されるため、話題を繰り返し説明せず続けて質問できます（例：「それはどのチャンネルですか？」）。この履歴は6時間使われないと自動的に削除されます。

### コンテキストの管理とリセット
`/hanacontext` パネル内では以下の操作が可能です：
- サーバー規則やコンテキストの削除
- 秘書設定のリセット
- API キー接続状態の確認

## 3. 推奨される Discord 権限

Hana は完全な管理者（Administrator）権限を必要としません。以下の必要最小限の権限を付与してください：

| 権限 | 使用目的 |
| :--- | :--- |
| `View Channel` | テキストおよびボイスチャンネルの閲覧 |
| `Send Messages` | チャットメッセージの送信・返信 |
| `Read Message History` | 会話の文脈を理解するための履歴参照 |
| `Embed Links` | 埋め込みカードの表示（`/travelphoto`、プロフィール、案内表示に必須） |
| `Attach Files` | 日本の旅行写真の添付 |
| `Use Application Commands` | スラッシュコマンドの実行 |
| `Manage Webhooks` | **NPC システム（`/npc`）に必須**（キャラクターとしての発言） |
| `Connect` & `Speak` | **TTS 読み上げ（`/tts`）に必須**（ボイスチャンネル参加と発言） |
| `Send Messages in Threads` | スレッド内でのメッセージ送信 |

## 4. トラブルシューティング

1. **Hana がチャットで返信しない**:
   - そのチャンネルで `/setroomai` が実行されているか確認してください。
   - Hana に `View Channel`、`Send Messages`、`Read Message History` があるか確認してください。
   - チャンネルの権限オーバーライド（Deny 設定）を確認してください。
2. **サーバー秘書が返信しない**:
   - `/hanacontext` で選択されたチャンネルと一致しているか確認してください。
   - 登録した API キー（Gemini / OpenRouter）のクォータに余裕があるか確認してください。
3. **NPC が返信しない**:
   - チャンネル内で Bot に `Manage Webhooks` 権限が付与されているか確認してください。
   - NPC のメッセージへの返信（リプライ）か、名前を含めた投稿になっているか確認してください。
4. **`/travelphoto` で写真が表示されない**:
   - 該当チャンネルで Hana に `Embed Links` 権限が付与されているか確認してください。
