# ホーム

Hana は、日本時間に基づく生活ルーチン、ロールプレイ用カスタム Webhook NPC、専属サーバー秘書デスク、音声読み上げ（TTS）、そして多彩なコミュニティコマンドを備えた Discord アプリケーションです。

> 🌸 Hana はタイ語・英語・日本語の自然な会話に対応しています。

## 主な機能一覧

| カテゴリ | 主な特徴 |
| :--- | :--- |
| **Hana AI 雑談** | 日本の時間割ルーチン（登校・部活・ゲーム）を持ち、親愛度や長期記憶を育む日常会話 |
| **NPC ロールプレイ** | 専用アイコンと名前を持つ Webhook を介して発言し、返信や呼びかけに応答するキャラクター |
| **サーバー専属秘書** | サーバーの規約や案内、チャンネル情報のみを正確に回答する専用アシスタント窓口 |
| **音声読み上げ（TTS）** | メンションやリンクを自動除去し、スパム防止制御を備えたボイスチャンネル読み上げ |
| **旅行写真＆Fun** | Pexels 連携の日本各地の旅行風景写真、リアクション用 Anime GIF、ミニゲーム |
