# メモリーと関係性

## メモリー

Hana のメモリーは **Discord User ID + Server ID** ごとに分かれています。あるサーバーの会話が別のサーバーに混ざることはありません。関係性も同じようにサーバーごとに分けています。

`/settingai` では次ができます。

- このサーバーの会話のメモリー、ピン留めした情報、関係性の要約を見る
- プロフィール、タイムゾーン、パネル表示に使う言語を編集する
- 返信時のメンションとリアクションのオン・オフを切り替える
- サーバーごとに分ける前の古いメモリーをこのサーバーへ移す
- このサーバーのメモリーを削除する、または全サーバーのメモリーの削除は確認手順を挟みます

年齢、本名、国など、入力していない情報を Hana が推測することはありません。

> 記録されたくない場合は `/settingai` からメモリーを削除してください。このサーバーのメモリーと関係性スコアの両方が消えます。

## 関係性

関係性スコアはユーザーとサーバーごとに分かれているため、他のサーバーの成績には影響しません。

礼儀正しく意味のある会話で少しずつ上がり、スパムでは上がりません。

圧力、境界線を越える行為、失礼な言葉、真剣な交際要求などで下がることがあります。Hana は丁寧に断り、友達としての境界線を保ちます。

Hana が少し距離を取るよう頼んだ後、元の状態に戻るには **通常の会話が3回以上** かつ **3日以上** の時間が必要です。

Hana はメモリーを使って突然メンションしません。不要な通知を避けるため、先に話しかける機能は削除されました。

## 対応している言語

Hana は書かれた言語と同じ言語で返答します。**タイ語・英語・日本語** に対応しています。対応していない言語で書くと、「この3言語しか読めない」と伝えて、AIプロバイダーにメッセージは送信されません。

パネルとメッセージに使う言語は `/settingai` → **個人情報と時刻** → **🌐 あなたの言語** で選べます。「自動」を選ぶと、話している言語に合わせます。
