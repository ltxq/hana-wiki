# Memory and relationship

## Memory

Hana keeps memory separately by **Discord User ID + Server ID**, so a conversation in one server does not bleed into another. Your relationship state is scoped the same way.

In `/settings` you can:

- Choose the language Hana uses for its panels — the menu is on the **first page**
- Edit your personal profile and time zone
- Turn reply mentions and reactions on or off
- Delete your personal data with a confirmation step from the **Data** page

Memory is now short-term, so the old "view memory" button was removed. Memory and relationship data always stay scoped to the server they came from and cannot be shared across servers.

Hana must not guess details you did not provide, including your age, real name, or country.

> If you would rather Hana kept nothing about you, use `/settings` → **Data** → **Delete all**. That removes both this server's memory and your relationship score here.

## Relationship

Relationship score is separated by user and server, so it never affects your standing elsewhere.

The score grows slowly from respectful, meaningful conversation and does not grow from spam.

The score can fall for pressure, boundary crossing, rudeness, or serious romantic requests. Hana declines politely and keeps a friendship boundary.

After Hana asks for some distance, it takes **at least 3 ordinary conversations** and **at least 3 days** before things return to normal.

Hana does not use memory to send unsolicited proactive tags. That feature was removed to avoid disturbing members.

## Supported languages

Hana replies in the language you write in. Thai, English, and Japanese are supported. If you write in a language Hana does not support, it tells you it can only read those three, and your message is not sent to an AI provider.

You can pick the language Hana uses for its panels and messages on the **first page of `/settings`** — choose Thai, English, Japanese, or "Automatic" to follow the language you chat in.
