# Command Directory

An overview of all Hana Slash Commands grouped by feature category:

---

## 💬 Hana AI & User Settings

Chat casually with Hana, monitor her daily routine, and customize personal preferences.

| Command | Description |
| :--- | :--- |
| `/setroomai` | Activates Hana AI chat room for natural casual chatter |
| `/unsetroomai` | Deactivates Hana AI chat in the current channel |
| `/guildbook` | Displays the interactive guide inside Discord |
| `/statusai` | Shows Hana's current daily routine based on Japan Standard Time |
| `/settings` | Opens your private panel — language on the first page, replies, timezone, profile, data |
| `/profile` | Shows your profile card and relationship score with Hana |

👉 Learn more: [AI and Settings](ai-and-settings.md)

---

## 🎭 Custom Roleplay NPCs

Create and control immersion characters that reply via Discord Webhooks with distinct avatars and display names.

| Command | Description |
| :--- | :--- |
| `/npc` | Opens one button panel for everything: create, list/filter, manage (model, profile, keys, channel), and delete. No subcommands to memorise. |

👉 Learn more: [Custom Roleplay NPCs](npc-roleplay.md)

---

## 🏢 Server Administration & Secretary Desk

Tools for server owners and administrators to maintain community guidelines.

| Command | Description |
| :--- | :--- |
| `/hanacontext` | Manage server context and configure the **Dedicated Server Secretary Desk** (also available as `/secretary`) |
| `/admin` | AI system admin hub for configuring the server's **central API keys** (moderators only) |
| `/hanainsights` | Displays this week's AI quota and the features active for everyone (all free) |

👉 Learn more: [Server Owner Guide & Secretary Desk](../roomai-and-permissions.md)

---

## 🔊 Text-to-Speech (TTS)

Summon Hana to your voice channel to read chat messages with automatic link and mention filtering.

| Command | Description |
| :--- | :--- |
| `/tts` | Makes Hana join your voice channel and read text messages aloud |
| `/leave` | Disconnects Hana from the voice channel immediately |

👉 Learn more: [Text-to-Speech (TTS)](tts.md)
